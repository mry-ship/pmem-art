## 二、链型分类（约 30 条链统计）

- **A 同物升级/生长**：几乎所有生成器和植物链（Toolbox、Tree、Oak、Trolley、Beach Bucket）。
- **B 同店不同货，价值递增**：订单链里最常见（MM Cakes、MM Tools、GH Coffee、Love & Pies Hot Drinks）。
- **C 过程叙事**：原料 → 加工 → 成品 → 套餐（GH Bread、GH Potatoes、MM Flowerpot）。
- **D 末档收尾**：套装、量、包装，通常只在最后 1–3 档（Family Bucket、Bucket of Sliders、Luxe Cheeseburger Meal、Sugary Tea Party）。
- **E 品种/体型梯**：Cats、Topiaries。
- 成品链通常是 **B + C，末段 D**。

## 三、升级是怎么做的

1. **邻档至少变一项**：容器、份量、完成态、件数、物种/工具。GH 咖啡中段大量靠**同一只杯上加件**：加碟 → 换花纹 → 加方糖和勺 → 拉花，都合法，因为件数或剪影看得出。
2. **体量几乎不变**：GH Decaf Coffee 前 12 档主体占卡高 0.83 / 0.87 / 0.87 / 1.00 / 0.83 / 0.87 / 0.92 / 0.88 / 0.90 / 0.90 / 0.94 / 0.94（本仓库实测），不单调，L4→L5 还缩小。竞品靠剪影和件数分档，不靠放大。末档才是全表最完整、占格最满的一件。
3. **前朴素、后犒赏**：配料、附件、第二件物品晚出现。末档常是套装、盛宴、或一体系统（茶具套装、水管系统、风琴）。
4. **没有发光特效**：MM、GH、TT 的精灵都没有「光效」；高档靠构图变大（一套、一摞、一个场景），不靠闪光。
5. **家族靠配色与同一机位**：MM 工具全是橙柄灰金属同斜角；GH 咖啡全是白蓝瓷。不靠同一纹样。
6. **链长**：生成器 5–12，成品 5–17，常见 7–15；订单链多 10–15；活动链更短（MM Pastries 8）。8 档对应一条短支链。

## 四、渲染

- 3/4 俯视，约 30–45°。
- 光从左上来，软影落右下（MM 精灵里可见）。
- MM：软塑胶 + 细深色描边；**GH：更亮更软，几乎无描边**；TT：半绘画感，无描边。
- 精灵本身透明底，格子由游戏界面给：TT 用米色圆角方块，GH 用浅蓝圆角卡。

## 五、常见翻车（对应我们的禁令）

- **主题漂走**：TT 咖啡 → 纸巾 → 折纸鹤。
- **邻档像双胞胎**：GH Decaf 与 Regular Coffee 只差一个碟；MM Flowerpot 第 7、8 档只差土。
- **同名多档**：Love & Pies「Drinks Tray (Lvl 2–5)」一个名字占四档。
- **每档重画一个身份**：dmnd.games 一篇文章称整链像「换装」。他们的解法：每个提示词都重复同一份固定身份说明，只写每档**看得见的升级**，先把整链当一张总表检查。（二手来源，只用来佐证本仓库做法。）

# App Icon · 多维审稿透镜（通用）

App Icon 不是「材质够不够高级的小插画」。它活在**商店栅格 / 桌面九宫格**里，和旁边一堆图标抢 60px 注意力。出图前按下面七层过；任一层挂了，识别度或安全区压分。

## 0. 对标材料（先决）
- 先看同品类**真上架图标**（App Store / Play 图标本尊），不是海报、不是 UI 截图裁角。
- 只抽密度与思路写进提示词；**禁止垫像素抄脸/抄构图**。
- 题材名写死（「草莓」「国王半身」），短 prompt 易跑题成心形/杂物。

---

## 1. 商店栅格体验（用户怎么找你）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 并排可认 | 和竞品并排扫一眼能停下来 | 灰糊一团、和邻图标撞色撞形 |
| 品类暗示 | 剪影回答「这是什么游戏/工具」 | 抽象装饰看不出品类 |
| 记忆点 | 一个符号反复出现仍是它 | 每版换主体、靠文字解释 |

## 2. 小尺寸视觉（60px / 29px）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 剪影优先 | 去色仍认主体 | 靠密纹理、细籽、水滴噪点认 |
| 夸张体块 | 轮廓加厚、五官/部件可读 | 写实微细节一缩全糊 |
| 单焦点 | 画面只有一个英雄 | 多角色小场景、角标字、贴纸堆 |

## 3. 主体重要程度（符号层级）
1. **P0 英雄**：角色半身 / 超大单符号——占满安全区光学主体  
2. **P1 身份附件**：冠、萼、关键道具——服务 P0 可读，不另开战场  
3. **P2 底衬**：渐变/色块——只负责对比与品牌气温  
4. **禁止入画**：Slogan、副标题、多 UI 控件、第二英雄  

权重：P0 >> P2；P2 抢戏 = 棚拍病。

## 4. 画幅与安全区（上下左右）
| 带 | 合同 |
| :--- | :--- |
| 母版 | `1024` **满幅直角**，系统自己套圆角；禁止预烤圆角/透明缺角 |
| 安全区 | 主体落中心 **72%–80%**；角区留给遮罩 |
| 密度 | 英雄**尽量撑满**安全区（头肩特写或超大符号） |
| 忌 | 小物漂浮 + 大留白「产品静物照」 |

休闲角色标（如 RM 国王）：半身撑满。  
休闲符号标（如糖块/草莓）：同一密度——**超大单颗**，不是桌面上的小糖。

## 5. 颜色构造
| 层 | 做法 |
| :--- | :--- |
| 底衬 ~70% | 一块干净主色或简单渐变，服务对比 |
| 主体 ~20% | 高饱和、与底衬冷暖或明度对立 |
| 点缀 ~10% | 高光、宝石、籽——成块，不成噪 |
| 对比铁律 | 暖主体×冷底（或反过来）；低对比粉灰底直接挂 |
| 禁止 | 底衬花纹比主体还热闹；霓虹杂色乱入 |

## 6. 光影与材质（套件）
- **一主光**（常上左），接触阴影轻，顶缘可读高光。  
- 材质跟品类：软糖 SSS / 角色肤塑 / 金属冠——但**形先于质**；质感再好剪影糊也白搭。  
- 忌全画面同一廉价塑料、或棚拍油镜盖过剪影。

## 7. 整体风格对齐
- 图标是品牌脸，须与游戏内主视觉**同一渲染品类**，但构图是「特写符号」不是「缩略海报」。  
- 角色标：大脸+表情；物件标：夸张可读的一件物。  
- **缺画风**：默认对标同品类顶级上架图标气质（密度/剪影/材质通感），禁止泛插画小海报；仍禁止垫像素抄脸。  
- 改版可微调，勿无更就换英雄。

## 出图前最小检查（可贴进 revised）
```
[ ] 看过同品类真上架图标（非海报）
[ ] 缺画风时已写同品类上架气质（非泛插画）
[ ] 主体名写死；单符号；无字
[ ] 满幅直角；主体撑满 72%–80% 安全区
[ ] 60px 剪影可认；无微细节噪点
[ ] 底衬高对比服务主体，不抢戏
[ ] 一主光；形 > 质
```

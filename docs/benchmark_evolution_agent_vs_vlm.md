## 解读

1. 报告正式分是 harness 剧本五维（`agent_absolute_5d`），不是 VLM。
2. 本表用 `gpt-5.6-sol` 对同一批 **PIL 示意过程图** 做 Absolute-5D 盲评。
3. VLM 系统性低分（约 1–7）：把图判成「几何示意图/调试截图」，无一张 ≥9.5。
4. 离线旁证约 8.0–8.5，夹在 Agent 剧本分与 VLM 真看图之间，但也不能当达标主尺。
5. 结论：这份演进报告证明的是 **记忆/Warm-Start 流程**，不是真实生图画质；要 VLM 主分闭环需真实出图 + `independent_vlm`。

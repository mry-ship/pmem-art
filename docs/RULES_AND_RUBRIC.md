## 2. 收敛强度参数 (`--scale low|medium|high|recompose`) 内部机制

在 `pmem_art.py converge` 与 `/pmem-draw` 中，支持通过 `--scale` 与 `--recompose-dir` 控制收敛幅度：

```bash
# 1) 低强度（只修缺陷，锁死原图机位/姿态/元素数量）
python3 pmem_art.py converge start --session s_low --scale low --goal "..." --ref-image ref.png

# 2) 中强度（默认：保持构图框架，补足光影层次与材质微肌理）
python3 pmem_art.py converge start --session s_med --scale medium --goal "..." --ref-image ref.png

# 3) 高强度（Showcase级：允许大胆重构镜头张力、重做戏剧化光影与叙事细节）
python3 pmem_art.py converge start --session s_high --scale high --goal "..." --ref-image ref.png

# 4) 定向改构图模式（按用户明确指令改变机位/景别/主体位置，100%保留画风基因）
python3 pmem_art.py converge start --session s_rec --scale recompose \
  --recompose-dir "从胸像正面特写改为复古阳光植物画室全景构图，主体移至右侧三分点" \
  --goal "..." --ref-image ref.png
```

### 四档 Scale 内部参数表 (`CONVERGE_SCALE_PROFILES`)

正式分不再按档位五维加权。`converge start` 会按画面媒介归入十一家之一，用六维加权调和平均打分（构图 / 光影 / 透视 / 质感 / 风格 / 无瑕疵；无瑕疵固定 25%，其余五维按家族分配）。四档只控制提示词改动预算、能否换机位或重做光影。

| Scale 档位 | 定位 | 正式分 | `next_fix` 改动预算 (`max_prompt_delta_ratio`) | 允许重构构图 (`allow_recompose`) | 允许重做光影 (`allow_lighting_overhaul`) | 单轮最低跃升目标 (`min_round_leap`) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`low` (低强度)** | 只修解剖/杂色/纸纹缺失，不改机位、姿态、元素和布局 | 六维调和平均 · 权重按媒介家族 | `<= 20%`，相对第一轮 | `False` | `False` | `+0.10` |
| **`medium` (中强度·默认)** | 锁机位；允许小幅姿态/局部布局/光影；不增删主体、不做整体 recompose | 同上 | `<= 40%`，相对上一轮 | `False` | `True` | `+0.15` |
| **`high` (高强度)** | 大胆跃升+可加风格内叙事；可改机位/构图/元素数；forbid=`no_identity_swap` | 同上 | `<= 80%`，相对上一轮 | `True` | `True` | `+0.20` |
| **`recompose` (定向改构图)** | 按 `--recompose-dir` 换机位；保持画风与身份（正交于强度轴，与 bold 拆开） | 同上 | `<= 85%`，相对上一轮 | `True` | `True` | `+0.20` |

## 3. 六维严苛审图标准与反虚高机制 (Anti-Inflation Rubric)

针对早期审图中曾出现的「因未乱加配饰/基本完成度达标而给分偏高（如 Case 02 R2 曾虚高至 9.65 分，实际严苛重审为 8.80 分）」问题，六维审图强制执行以下**严苛扣分准则**。正式分是加权调和平均，不要手填总分。无瑕疵固定占 25%，与另外五维一样盲评。

1. **构图与视觉张力 (`Composition`)**：
   - 若仅平庸照搬参考图的呆板居中/证件照裁切、缺乏前景压角或明度重心锚点，**最高不超过 8.6 分**。
2. **光影与色彩层次 (`Lighting & Color`)**：
   - 必须具备明确的 `70-20-10` 冷暖主辅色比例与主光/轮廓光/环境反射光三层分离；平光或简单一刀切二分阴影**最高不超过 8.8 分**。
3. **透视与解剖结构 (`Perspective & Anatomy`)**：
   - 严格检查五指关节、鞋带透视、建筑消失点与近中远三层空气透视。
4. **物理媒介质感 (`Texture & Material Authenticity`)**：
   - 严禁将「数字噪点滤镜」误判为真实纸纹！例如 300g 冷压粗纹纸油画棒必须看见**未填满的纸纹凹槽飞白（Unpainted Paper Tooth Gaps）**与**厚涂蜡质笔触（Dry Impasto）**；若涂色过于均匀死板，质感项直接扣至 **8.8 分以下**。
5. **规格与风格完成度 (`Spec & Style`)**：
   - 仅作为基础底线项，防止「不出错即高分」掩盖画面冲击力与质感短板。家族权重里这一维通常落在 11%–19%。
6. **无瑕疵 (`Flawlessness`, 固定 25%)**：
   - 与另外五维一样盲评 0–10，不另写瑕疵清单。脏边、多手、文字残影、糊成一团都打在这一维。缺这一维不能停。

### 3.1 克隆结构门禁（与总分并行，fail-closed）

门禁写在 `/pmem-draw` 的克隆合同里。`/pmem-clone-image` 只是点名锁定这一支的旧入口，不是另一套技能。

| 合同 | 触发条件 | 一票否决 / 压分 | R1 Prompt 结构底线 |
| :--- | :--- | :--- | :--- |
| **UI 弹框母版** | 模块 `ui.*`；`ui.PopupClone` **默认**空壳（除非 brief 写「中心插画/奖励插画」） | defects 含「中心礼盒/回声参考」→ 压分 ≤8.85 且 **不可 STOP**；九宫格或构图 &lt;8.5 不可 STOP | `ui_shell` |

### 反向分析结论与代码级修复 (`skills_kit/`)
1. **为什么之前自评普遍虚高 `0.5 ~ 0.99` 分？**
   - 生成端同时担任裁判时存在「Prompt 锚定效应（Prompt Confirmation Bias）」：模型看到自己写了“300g 粗纹纸”或“木漏日”，就默认画出来了并给出 `9.6+`；且对「不出错/不乱加配饰」过度奖励。
2. **已落地的代码修复**：
   - `parse_5d_dims()`：从各维分数算加权调和平均（有无瑕疵时走六维，否则走工艺五维），禁止手填总分。门槛维低于线时，正式分改取该维，并且不能停。像素离线分已停用，不进入正式分，也不再打印。
   - `audit_score_inflation()`：当缺陷描述含 `缺乏飞白 / 数字化噪点|痕迹|滤镜 / 照搬 / 呆板 / 平光` 等短板词时，自动将分数硬顶封死在 `<= 8.90`，强制进入下一轮（直到满 4 轮）。否定说法（`非数字化` / `未出现`）不误杀。
   - 缺陷栏为空或仅套话（`无明显硬伤` 等）时拒绝 `STOP_TARGET_REACHED`。
   - 收敛停滞预警 (`stagnated`)：当相邻两轮分差 `< min_round_leap` 且未达阈值时提示升级重构力度（**软预警**：不改分、不单独拒绝达标；真正挡达标的是分数/缺陷实质/物理图闸门/prompt Δ 超限）。
   - **安全收敛五项护栏（硬接线：`skills_kit/converge_policy.py` → `judge_auto` / `converge generate|judge`；批跑经 `scripts/v8_skill_converge_policy.py` 再导出）**：
     1. **每轮垫最初参考图**：`low` / `medium` / `high` / `recompose` 的 `pad=auto` 每一轮都垫最初的 `style_ref`，修正只写进提示词，不链成图。风格跳跃（`recompose_bold` / `style_jump` / 目标里写了「风格跳跃」）不垫旧风格参考，也不垫上一轮成图。`pad=previous` 仍可显式链式。会话同时记下策略建议垫图和本轮实际垫图。
     2. **解剖一票否决（缺维 fail-closed）**：人物/动物/机械 `透视与解剖 < 7.5` 时，正式分改取这一维，禁止 `STOP_TARGET`。像素、Q版、平涂、水彩、剪纸用更低的风格门槛（6.5 / 6.8 / 7.0 / 7.2 / 6.5），只容那一维按媒介偏低；融化、多手、断肢、塌缩取消容错。纯场景低于 `6.0`（等轴、正交是 `5.5`），或缺陷写了结构塌缩，才禁停。偏低的光影或质感交给调和平均，不再单独上调。六维尺缺了透视或无瑕疵，人物仍然不能停。界面的门槛是结构 `< 7.5` 或管线 `< 8.0`（管线不进乘积）。图标 A 的识别或安全区 `< 8.0`、图标 B 的笔画或识别 `< 8.0`、图标 C 的剪影/脏底/有字，同样改取该维并不能停。旧的技能加和尺没有透视维，不拿解剖去否决。
     3. **R4 起掉分/平台安全早停**：`round >= 4` 且相对历史最高掉 `≥ 0.5` 或连续不创新高 ≥2 轮时早停，保底历史最高分轮次。
     4. **按主体注入 R1 结构底线（`classify_subject` + `build_r1_structure_floor`，非 continuation 才注入）**：词表中英都参与匹配，不设条数上限。写入提示词的是英文结构句，中文只在回显里给画师看。人物写关节与双眼；动物按物种；机械写接缝、不写人类瞳孔；`character.*` 没写物种只写轮廓连续；纯场景只写灭点。任务型 UI（模块 ui/icon、HUD、九宫格）不注入。button/menu/icon/界面单独出现才算 UI，和人物或场景写在一句里时跟主体走。认不出的 brief 返回空串。
     5. **精简回流**：日常 `judge` 在下一轮改点是空话时，用 `reflow_fix_text` 写成 ≤2 条（中文回显，同一条的英文写入下一轮提示词）。和主体打架的改点会换掉（场景上的人类关节、动物上的人类瞳孔）。弱解剖时去掉体积光。没声明玩具/卡通/Q版时，生成前剥掉 vinyl、chibi、搪胶、桶身、金琥珀双描边。`不要卡通` 这种否定不算声明。参考图文件名和路径不参与主体分类。评分失败重试一次，仍失败不灌入泛化套话。
   - 可选独立视觉裁判见 `vlm_judge.py`（配置 API key 后覆盖 CLI 自评六维）。

## 🚀 玩家与美术三步极简上手（丢图 → 选档 → 说想法）与四档 Scale 动态达标收敛详解

即使你不是程序员，在 Cursor 里使用 `pmem-art` 也只需要**三步**：
1. **第一步 · 丢图（Style Reference）**：把任意一张你喜欢画风或想优化的参考原图丢进对话。哪怕你的项目是**刚刚新建的空项目（`0` 条项目私有记忆）**，系统也会自动挂载 `~/.pmem-art/shared/` 下的 **14 张跨项目全局基础美术卡片**（70-20-10 色板配比、三层大气透视、黄金螺旋构图、300g 粗纹纸/厚涂肌理等通用美术规律）来拆解原图基因。
2. **第二步 · 选档（`--scale low | medium | high | recompose` 四档切换）**：根据你想保持原图还是大胆重构，任选一档。
3. **第三步 · 说想法（Brief 主体身份锁定 + `--recompose-dir` 定向改构图）**：用大白话写出你的需求。**主体身份锁定原则**：无论选哪一档，系统默认严格锁死原图角色的**性别、物种、年龄段与核心外观身份锚点**（你也可以在 `--brief` 中显式标注角色特征），只升级构图、光影与镜头语言，绝不擅自篡改角色身份。

### 🎚️ 四档 `--scale` 完整定义、适用场景与动态达标停机表

四档控制的是提示词能改多少、能不能换机位或重做光影，不再单独决定打分权重。正式分一律是六维加权调和平均，权重按媒介家族（无瑕疵固定 25%）。  
更重要的是：**生图和审图分成两步（`converge generate` 只生图，`converge judge` 再审图）**。`converge step` 会直接拒绝。每审完一张，按该档目标分决定停还是继续（统一 `>= 9.50`）：

| Scale 档位 | 动态达标停机阈值 | Prompt 改动幅度上限 (`max_prompt_delta_ratio`) | 正式分 | 通俗定义、适用场景与为什么这样设置 |
| :--- | :--- | :--- | :--- | :--- |
| **`--scale low`**<br>低强度 · 保守修瑕 | **`>= 9.50`** | **`<= 20%`**<br>只和第一轮比 | 六维调和平均 · 权重按媒介家族 | **只修局部瑕疵**。不改机位、姿态、元素数量和布局。提示词改动不超过 20%。原图离 9.5 远时换 medium 或 high。 |
| **`--scale medium`**<br>中强度 · 小优化（锁机位，默认） | **`>= 9.50`** | **`<= 40%`**<br>相对上一轮 | 同上 | **锁机位的小优化**：可小幅姿态/局部布局/光影；仍禁换视角、整体 recompose、大改元素清单。按媒介补侧逆光、空气层次与材质（人物/厚涂默认可写次表面散射；UI/pixel/粉彩等扁平媒介不加 SSS）。 |
| **`--scale high`**<br>高强度 · 大胆跃升+可叙事 | **`>= 9.50`** | **`<= 80%`** 相对上一轮 | 同上 | **大胆跃升 + 可加风格内叙事**：可改机位/构图/元素数；forbid 用 `no_identity_swap`（不换主体身份）。与 `recompose` 正交——后者须 100% 跟 `--recompose-dir`。`min_rounds_before_stop` 默认 2。 |
| **`--scale recompose`**<br>定向改构图模式 | **`>= 9.50`** | **`<= 85%`** 相对上一轮 | 同上 | **按 `--recompose-dir` 换机位**。没有这句方向不能开档。画风和身份仍要保住。`min_round_leap` 与 high 同为 `+0.30`（正交轴，不倒挂）。约束句写在生成词末尾。 |

### 🔍 独立 VLM 裁判乱序盲评验证（`BLIND_ART_01..12`）与 Cursor 防自评虚高机制

为什么之前会出现“第 2 轮自评 9.65 分、但肉眼看还不如单次直出”的现象？因为**让刚写完 Prompt 的同一个模型自己评自己的图，会产生严重的「提示词确认偏误」**。为此 `skills_kit/scoring.py` 内置了 `audit_score_inflation()`，并可选用 `vlm_judge.py` 独立视觉 API；并将 12 张候选图匿名乱序交给独立 VLM 盲评：
- **精准戳破第 2 轮同会话自评虚高（`+0.51 ~ +0.99` 分）**：案例 02 第 2 轮自评 `9.65` → 独立盲评仅 **`8.66`**；案例 03 第 2 轮自评 `9.72` → 独立盲评仅 **`8.77`**，全部未满高强度阈值，强制触发第 3 轮深度重构！
- **独立盲评实测证实第 3 轮相对第 2 轮跃升**（盲评分 ≠ 系统加权达标线 `>= 9.50`；下列「终轮盲评」仅对照肉眼/盲评，不代替闸门）：

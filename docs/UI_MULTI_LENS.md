# 主菜单 · 多维审稿透镜（通用）

UI 不是「画风够不够高级」。出图前按下面六层过一遍；任一层挂了，结构维压分。

## 0. 对标材料（先决）
- 必须是**该品类真实按钮界面截图**（顶栏/底栏/CTA 都在）。
- 禁止用 keyart、叙事插画、茶会气氛图冒充 HUD。
- 只抽分区与工艺写进提示词，**禁止垫像素抄界面**。
- 店面/外网下载的对标图放 `downloads/`（或 `下载/`），**不进工作台画廊**；不要丢进 `assets/`。
- **范例 ≠ 默认**：Royal Match 类（头像|币|心|星|右上设置；Level+Area；底栏五 Tab）只作三消/装修休闲参考；RPG/超休/工具 App 另抽真图。

---

## 1. 用户体验（一手怎么用）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 三秒任务 | 一眼知道「下一步点哪」 | 一堆同权重大钮，没有主任务 |
| 触达 | 主 CTA 在拇指区或真图同款热区 | 设置独占一行浪费高度 |
| 路径 | 高频入口短路径（跟对标） | 臆造侧栏四钮丢掉真图进店方式 |
| 误触 | 系统钮可点不抢主任务 | 齿轮比主 CTA 还抢眼 |

## 2. 用户视觉（一眼怎么扫）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 扫视顺序 | 顶状态 → 场景情绪 → 主任务 → 导航 | 中部装饰与侧栏同时喊 |
| 主次面积 | 主任务明显大于次入口 | 次钮与主任务同大 |
| 呼吸 | 顶栏单行压矮，场景能露 | 顶栏拆两层 |
| 不压脸 | 控件不盖角色脸 | 主钮盖脸 |

## 3. 按钮重要程度（信息层级）
1. **P0 主任务**（形态跟对标：单 PLAY / Level+Area / 其它）  
2. **P1 进度伴随**  
3. **P2 资源状态**  
4. **P3 主导航**（有则按真图；休闲可有底栏）  
5. **P4 次入口**  
6. **P5 系统**（常见右上，以真图为准）  

权重反了 = 结构挂。

## 4. 上下方设计（垂直分区）
| 带 | 职责 | 合同 |
| :--- | :--- | :--- |
| **顶** | 身份 + 资源 + 系统 | 尽量单行；系统勿独占第二行 |
| **中** | 场景 / 情绪锚 | 脸清 chrome |
| **中下** | 主任务区 | 跟对标真图，勿无据锁死一种 CTA |
| **底** | 全局导航（若有） | 语义跟品类；禁对战大厅乱套 |

## 5. 颜色构造
场景大面积稳住 → chrome 一族 → 行动色只给主任务；资源语义色（若有）固定。色服务于层级。

## 6. 整体风格对齐
- 同品类描边体积投影；场景底板 + 可点 chrome；禁插画海报飘钮。
- **分区对标了谁，渲染品类必须同系**：玩家未点名画风且无概念图时，chrome 气质跟 §0 同一竞品系；禁止结构抄休闲主页、材质却另起泛插画。
- **范例 ≠ 默认**：未点名三消/装修时禁止默套 Royal Match 骨架。

## 出图前最小检查
```
[ ] 该品类真按钮截图已看，非 keyart；对标品类名已写
[ ] 未点名三消/装修时未默套 RM 骨架
[ ] 渲染品类与布局对标同一竞品系（缺画风未另起插画风）
[ ] 顶栏单行；系统钮不抢戏
[ ] P0 主任务面积/位置成立（形态跟对标）
[ ] 底栏有无跟真图，未乱套对战大厅
[ ] 色与套件服务层级
[ ] 脸与 CTA 不互压
```

结论

材料锁生效了：新旧并排时，新稿不再是八件各用各的木纹和镜面金属，而是同一条塑料握把产线。评分也没再把这种半成品写成过线。

门槛还没过。文具卡在铅笔木色和长尾夹的裸丝握把，乐器卡在口琴棱纹。第三轮说明改点不能只喊失败件，还得把件数和左右顺序再锁一次，否则整张会退步。

# 游戏鱼类合成梯 · 关系稿 1

画风：饱和友好卡通鱼，圆润倒角软阴影，浅灰棚空底只有接触影，无脸无等级字。不是写实鱼，不是搪胶。

同一条鱼一路长零件。两件相同的这一档合成下一档，画面仍只画一条。

| 档 | 物件 | 剪影家族 | 较上档 | 新增零件 | 合成理由 |

| L2 | 胸鳍鱼 | 豆身+一对侧胸鳍 | +小 | 一对胸鳍 | 两件豆鱼合成，身体两侧长出胸鳍 |
| L3 | 尾扇鱼 | 胸鳍身+扇形尾 | +小 | 扇形尾鳍 | 两件胸鳍鱼合成，尾端展开成扇 |

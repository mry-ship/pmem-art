# 青金治疗药 / 蜜桃糖 · 关系 3 稿（第一段，不出图）

画风一句（药）：同族矮切面玻璃卡通药瓶，灰棚空底只有接触影，无木托无桌面无包装。
画风一句（糖）：同族蜜桃软糖卡通，零件长在糖上；空底只有接触影；不裹糖纸、不上纸托、不摆托盘。

## 稿 1
药：空瓶 → 加塞仍空 → 半药 → 满药 → 签环叶饰 → 瓶底小金足 → 塞顶晶冠 → 冠沿光环神瓶。
糖：小软糖 → 胖软糖 → 糖霜结在糖面 → 叶片从糖上长出 → 宝石嵌进糖面 → 王冠长在糖顶 → 星尖 → 神糖。
未过：金足容易画成木桌托盘；糖霜后容易改成糖纸包装链。

## 稿 2
只改：金足是瓶子自己的小金足，不是桌子。叶片/王冠/宝石都长在同一颗糖上，不是另包一层纸。
其余锁住。

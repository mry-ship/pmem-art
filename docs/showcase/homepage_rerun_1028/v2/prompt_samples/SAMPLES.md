# /pmem-prompt 样例集（测试展陈 · 不生图）

判定类型后按该类清单扩写；点选前禁止开生图。

---

## 样例 P1 · 普通图

**玩家原话**：青瓷小猫  
**判定类型**：普通图 · 将交给：`/pmem-draw`

| 方案 | 中文目标句 | 侧重 |
| :--- | :--- | :--- |
| A 静物棚拍 | 一只青釉小猫陶偶坐在米白绒布上，顶 45° 柔光，釉面湿润高光一条，浅景深 | 材质与高光 |
| B 窗边半身 | 青瓷色短毛小猫趴窗台，侧逆光透毛尖，纸感淡彩描边 | 光色与媒介 |
| C 俯视特写 | 俯拍青瓷小猫脸与一对尖耳占画面 70%，背景虚化苔绿 | 景别特写 |

## 样例 P5 · 合成梯关系稿

**玩家原话**：治疗药八档升级  
**判定类型**：合成梯 · 将交给：`/pmem-merge-ladder`（先关系 3 稿）

| 方案 | 关系叙事一句 | 画风一句 |
| :--- | :--- | :--- |
| A 青金药 | 空瓶→塞→半药→满药→签环→金托→晶冠→罩瓶 | 切面玻璃+暖金饰卡通道具 |
| B 蜜桃糖 | 裸糖→糖纸→贴纸→纸托→丝带→托盘→罩盒→礼盒 | 软塑胶糖果宫廷 |

说明：本类先交关系稿，说通后再一档一张正方形；不要直接交八张插画 prompt。

# 蜜桃糖 · 3 稿

## 稿1 没过
软糖 → 棒棒糖 → 扭结糖 → 马卡龙 → 纸杯蛋糕。前几档就断了：棒棒糖之后又退回包装糖；包装糖再跳马卡龙，把糖果焊进蛋糕。Travel Town 口香糖机是 Sweet Candies、Chocolates、Sprinkle Cakes 三条分开的。Merge Mansion 蛋糕链从纸杯蛋糕起，全是蛋糕。

## 稿2 补
改成糖果一条链：软糖 → 包装糖 → 棒棒糖 → 螺旋糖 → 糖葫芦 → 糖盒 → 糖果罐 → 糖果塔。
先加包装，再加棍，再加密纹，再换成糖衣果，再收成盒和罐。不进马卡龙、不进蛋糕。

## 稿3 定稿
画风：Merge Mansion / Travel Town 风格化卡通 3D 棋盘图标，不是产品实拍。每件完整落在相同大小的正方形格里。

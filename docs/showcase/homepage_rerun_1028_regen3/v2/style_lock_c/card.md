# 风格锁定卡片 · style.BoldCel

粗黑线平涂。橙暖描边与硬边高光，色块分层。样张：`ref1.jpg` 角色、`ref2.jpg` 道具。锁定卡图见 `final.jpg`（信息色板卡，未跑四轮闭环）。

同模块下一张开场必须带上下面的 HEX 和禁用词。

## 色板

| 层级 | 名称 | HEX |
| :--- | :--- | :--- |
| 主色 70% | 墨线黑 | `#0F0C0B` |
| 主色 70% | 暖麦肤 | `#BF794A` |
| 主色 70% | 金橙亮面 | `#FFC204` |
| 辅色 20% | 刃橙 | `#FC9700` |
| 辅色 20% | 夹克炭黑 | `#1C1A1A` |
| 点缀 10% | 橙暖描边 | `#F57C21` |
| 点缀 10% | 深橙影 | `#DE3D00` |
| 点缀 10% | 肤亮块 | `#D38D5B` |
| 点缀 10% | 肤暗块 | `#683B21` |
| 点缀 10% | 海军蓝缠柄 | `#173159` |
| 点缀 10% | 硬白高光 | `#F8F8F7` |

皮肤只许三层硬边：`#D38D5B` / `#BF794A` / `#683B21`。金属与刃面只许三层硬边：`#FFC204` / `#FC9700` / `#DE3D00`。

## 笔触 / 光影

粗黑闭合轮廓，赛璐珞平涂两到三层。暖橙侧逆光；发缘与领口橙暖描边高光 `#F57C21`。

## 负向禁用词

水彩软边、写实皮肤毛孔、软渐变、空气喷枪、厚涂笔触、油腻高光、脏暗阴影、过度霓虹。

## 可直接拿去画的句子

粗黑闭合轮廓 `#0F0C0B`，平涂色块分层：皮肤三层 `#D38D5B` / `#BF794A` / `#683B21`，刃面与金属三层 `#FFC204` / `#FC9700` / `#DE3D00`，发缘与领口橙暖描边高光 `#F57C21`，可加一条硬白高光 `#F8F8F7` 与海军蓝点缀 `#173159`，衣物炭黑 `#1C1A1A`。暖橙侧逆光，高光是平涂色块。禁止水彩软边、写实皮肤毛孔、软渐变、空气喷枪、厚涂笔触、油腻高光、脏暗阴影、过度霓虹。

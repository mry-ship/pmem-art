# P2 · 原画 / Key Art

判定类型：`原画 / Key Art` · 依据：原话写明「黄昏 Key Art」，主体是浮空遗迹的主视觉，没有操作控件 · 将交给：`/pmem-draw`（原画合同）

听懂的交付物：一张浮空遗迹的黄昏主视觉。玩家已锁定：浮空、遗迹、黄昏、Key Art。还不确定：遗迹是廊、塔还是城；有没有人物。四套都不放可识别人物，避免编造身份。画幅原话未锁，四套暂用 16:9 横幅，标为未锁定。无界面、无可读字。点选前不生图。

## 方案 A · 低机仰视

- **中文目标句**：一张商业完成度的黄昏主视觉，16:9。记忆点是一圈断裂的浮空石廊从画面下方切进来，人在廊底往上看。近景是廊柱下缘，中景是断开的拱，远景是黄昏天空。主光在画面右后方，暖琥珀，柱的底面吃冷紫反光。空气里有薄尘，远拱更淡。媒介是清晰的概念厚涂，边缘肯定，不是素描。没有人物、飞艇、现代建筑、界面和任何文字。
- **英文执行句**：Commercial key art, 16:9, no UI. Memory point: a broken ring of floating stone colonnade cutting in from the bottom, seen from underneath. Near layer is the column undersides, middle layer is the snapped arches, far layer is the dusk sky. Key light warm amber from the rear right; undersides take a cool violet bounce. Thin dust; distant arches fade by aerial perspective. Clear concept-art impasto with decisive edges, not a sketch. No people, airships, modern buildings, interface, or readable text.
- **本套侧重**：低机仰视、右后琥珀主光、冷紫底面。
- **相对原话改了什么**：把遗迹收成断廊；补了仰视分层和右后主光。画幅未锁定。
- **建议交给**：`/pmem-draw`

## 方案 C · 云海上俯

- **中文目标句**：一张商业完成度的黄昏主视觉，16:9。记忆点是一块浮空残基像暗岛一样趴在金橙色云海上，俯视能看见基座的破口平面。机位高、略斜，不是地图正俯。主体约占画面四成，四周是云。主光从上方偏右落下，顶面是黄昏金，基座底面是冷青灰。远云更淡、更暖。媒介是干净的商业概念图，结构可读。没有军队、英雄、界面和文字。

Distant clouds paler and warmer. Clean commercial concept rendering with readable structure. No armies, heroes, interface, or text.

- **中文目标句**：一张商业完成度的黄昏主视觉，16:9。记忆点是一段悬空断阶通向没有落点的空中，台阶在画面左下，尽头没入右上的暮色。机位是台阶侧面的平高一点。主光从左面切进来，台阶侧面是暖橙，右缘是冷紫，笔触用油画厚涂，色块宽，能看见颜料厚度。近阶实，远阶糊在空气里。没有人往上走，没有栏杆广告，没有界面和文字。

Near steps solid, far steps lost in air. No climber, no signage, no interface, no text.

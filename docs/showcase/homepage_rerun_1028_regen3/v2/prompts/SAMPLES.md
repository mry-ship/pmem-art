## 样例 P5 · 合成梯关系稿

**玩家原话**：治疗药八档升级。先写关系，说通后再一档一张  
**判定类型**：合成梯 · 将交给：`/pmem-merge-ladder`  
**文件**：`p5.md` · 3 套关系稿（非八张插画 prompt）

| 方案 | 关系叙事一句 | 画风一句 |
| :--- | :--- | :--- |
| A 瓶阶加件 | 管→塞→箍→圆瓶→耳→水晶塞→金带→足 | 粉青厚涂静物，暖侧光 |
| B 剂量见光 | 同圆瓶：塞→剂量→刻度→透亮→亮核→口金→底金 | 冷白棚拍，玻璃通透 |
| C 丸盒成樽 | 丸→双丸→盖盒→釉盖→金沿→加高罐→耳→化液 | 药典水粉，平光纸底 |

说明：本类先交关系稿，说通后再一档一张正方形；不要直接交八张插画 prompt。

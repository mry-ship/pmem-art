# 风格锁定卡片 · style.InkWashSage

水墨淡彩。样张两张：松雾 `ref1.jpg`、茶盏 `ref2.jpg`。锁定卡图见 `final.jpg`（信息色板卡，未跑四轮闭环）。

玩家原话：从水墨淡彩样张锁苔绿主色、墨黑、米宣纸底与漫射纸感光；禁用霓虹与硬边赛璐珞。

## 笔触 / 光影

湿接淡彩，边缘渗进纸纹，断墨细枝。漫射纸感光，无硬主光、无轮廓光。

## 负向禁用词

霓虹、硬边赛璐珞、分阶明暗、均匀粗勾线、油亮高光、塑料青瓷、纯黑死黑、高饱和翠绿、赛博光、硬投影、矢量平涂、厚涂油彩。

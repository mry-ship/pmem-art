## 商业对标（诊断·非垫图）

- **对标品类**：休闲 merge **货柜道具 / 棋盘缩略**气质（表内默认 **Gossip Harbor 玩具货柜**：圆润厚实、软渐变糖釉、暖饱和、无硬描边 CGI）。
- **问题类型**：以 **完成度/画风统一** 为主（色相狂欢、塑料食物感），非需求理解错误；构图机位本身可留。
- **并排结论**：完成度接近商业道具缩略图，但色相冷暖与材质奶度未收到 GH 式「暖糖釉一整盘」；蓝果若保留需写入风格合同为「奇幻浆果」而非写实食物。

## ✅ 合理亮点

1. **托盘隐喻成立**：红伞蘑菇作承具，叙事一眼可读，适合道具 icon / 合成梯一格。
2. **黑底棚拍规范**：主体轮廓干净，无脏边，利于 UI 抠图或棋盘格嵌入（源图无真透明，交付需另出隔离底）。
3. **光源单一**：全件顶左柔光，无打架多光源，槽位风格统一。
4. **形体圆润**：符合休闲 3D 厚 silhouette，缩小仍可认芝士孔与伞盖斑点。

## ❌ 不合理 / 需返修点

1. **食物色相合同未锁**：蓝球果饱和度接近浆果玩具，与橙樱桃、暖黄芝士并列时像三套色系硬拼，削弱「一盘下午茶」合理性。
2. **芝士孔过几何化**：孔洞内壁缺少朦胧奶光与微糙边，塑料冲模感压过手绘软糖釉。
3. **承面压贴弱**：橙果与伞盖接触影偏软、偏浮，承具「托举感」不足。
4. **无瑕疵向对称**：蘑菇外缘起伏过于工整，stem 体积光影有轻微条带，显生成痕迹。

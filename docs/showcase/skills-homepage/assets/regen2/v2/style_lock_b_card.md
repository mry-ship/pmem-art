# 风格锁定卡片 · style.InkWashSage

水墨淡彩。样张两张：松雾 `ref1.jpg`、茶盏 `ref2.jpg`。色值从像素取样，不另开一张图。

玩家原话：从水墨淡彩样张锁苔绿主色、墨黑、米宣纸底与漫射纸感光；禁用霓虹与硬边赛璐珞。

同模块下一张开场带上下面的 HEX 和禁用词。

## 色板

| 角色 | 中文名 | HEX | 取样 |
| :--- | :--- | :--- | :--- |
| 主色 | 苔绿 | `#505848` | 松雾松冠最频簇 |
| 主色暗部 | 深苔 | `#404838` | 松冠暗簇 |
| 主色浅档 | 青瓷苔 | `#989888` | 茶盏盏身亮簇 |
| 辅色 | 墨黑 | `#101418` | 茶盏底最频 |
| 辅色 | 枝墨 | `#24241E` | 松干 |
| 底色 | 米宣纸 | `#E8E0D0` | 松雾纸底最频 |
| 底色亮 | 暖宣 | `#F0E8D8` | 纸亮簇 |
| 点缀 | 漫射纸白 | `#F1EEE1` | 盏沿高光平均 |
| 点缀 | 雾灰绿 | `#B7B7A8` | 松雾远雾主簇 |

面积随景别换，色值不换。松雾的大面积是米宣纸 `#E8E0D0`，苔绿落在松冠、远林。茶盏的大面积是墨黑 `#101418`，青瓷苔 `#989888` 落在盏身，高光收到漫射纸白 `#F1EEE1`。苔绿是低彩度橄榄灰绿，彩度停在样张这一档。

## 笔触

湿接淡彩。边缘渗进纸里，颜料沉淀出纸纹。线只出现在松枝和叶脉上，细、断、色为枝墨 `#24241E`。层次靠晕染和留白，明暗连续过渡。

## 光影

漫射纸感光，没有硬主光，没有轮廓光。松雾是暖纸色温的天光，远山对比被雾吃掉，收到雾灰绿 `#B7B7A8`。茶盏是柔的顶侧漫射，釉面高光是纸白 `#F1EEE1`，暗部停在墨黑 `#101418`，纸纹还在。

## 正向风格词

水墨淡彩、湿接、渗化、纸纹颗粒、低彩度苔绿、断墨细枝、青瓷釉、留白、大气透视、漫射纸感光。

## 负向禁用词

霓虹、硬边赛璐珞、分阶明暗、均匀粗勾线、油亮高光、塑料青瓷、纯黑死黑、高饱和翠绿、赛博光、硬投影、矢量平涂、厚涂油彩。

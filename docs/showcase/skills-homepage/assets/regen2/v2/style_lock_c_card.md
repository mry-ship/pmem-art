# 风格锁定卡片 · style.BoldCel

粗黑线平涂。橙暖描边与硬边高光，色块分层。样张：`ref1.jpg` 角色、`ref2.jpg` 道具。未生图。

同模块下一张开场必须带上下面的 HEX 和禁用词。

## 色板

色值从样张像素取样（角色肤色中位、发缘橙描边、剑身亮/中/暗面、缠柄、硬白高光）。比例是角色分工，不是单图像素占比。

| 层级 | 名称 | HEX | 用在哪 |
| :--- | :--- | :--- | :--- |
| 主色 70% | 墨线黑 | `#0F0C0B` | 粗黑闭合轮廓、头发、暗部大块 |
| 主色 70% | 暖麦肤 | `#BF794A` | 皮肤平涂中间调 |
| 主色 70% | 金橙亮面 | `#FFC204` | 刃面 / 金属受光主块 |
| 辅色 20% | 刃橙 | `#FC9700` | 第二层橙色块 |
| 辅色 20% | 夹克炭黑 | `#1C1A1A` | 衣物次暗面 |
| 点缀 10% | 橙暖描边 | `#F57C21` | 发缘、领口的暖色描边高光 |
| 点缀 10% | 深橙影 | `#DE3D00` | 最暗一层硬边色块 |
| 点缀 10% | 肤亮块 | `#D38D5B` | 颧骨硬边亮面 |
| 点缀 10% | 肤暗块 | `#683B21` | 下颌、颈侧硬边阴影 |
| 点缀 10% | 海军蓝缠柄 | `#173159` | 冷色小面积对照 |
| 点缀 10% | 硬白高光 | `#F8F8F7` | 刃上一条平直硬高光 |
| 点缀 10% | 徽记橙 | `#BE4D0D` | 胸前小标志 |

皮肤只许三层硬边：`#D38D5B` / `#BF794A` / `#683B21`。金属与刃面只许三层硬边：`#FFC204` / `#FC9700` / `#DE3D00`。

## 笔触与光影

- 线：均匀粗黑闭合轮廓，色块边界是折线。
- 渲染：赛璐珞平涂，两到三层色块。高光是一块平涂形状（发缘橙边、刃上白条），不是渐变。
- 光：暖橙侧逆光。角色发缘和领口用 `#F57C21`；道具左上受光，暗面收进 `#DE3D00`。
- 底不进锁。角色样张是近黑空底，道具样张是白底。

## 正向风格词

粗黑线、平涂、赛璐珞、色块分层、硬边、橙暖描边、硬边高光、闭合轮廓

## 负向禁用词

水彩软边、写实皮肤毛孔、软渐变、空气喷枪、厚涂笔触、油腻高光、脏暗阴影、过度霓虹

## 可直接拿去画的句子

粗黑闭合轮廓 `#0F0C0B`，平涂色块分层：皮肤三层 `#D38D5B` / `#BF794A` / `#683B21`，刃面与金属三层 `#FFC204` / `#FC9700` / `#DE3D00`，发缘与领口橙暖描边高光 `#F57C21`，可加一条硬白高光 `#F8F8F7` 与海军蓝点缀 `#173159`，衣物炭黑 `#1C1A1A`，小标志 `#BE4D0D`。暖橙侧逆光，高光是平涂色块。禁止水彩软边、写实皮肤毛孔、软渐变、空气喷枪、厚涂笔触、油腻高光、脏暗阴影、过度霓虹。

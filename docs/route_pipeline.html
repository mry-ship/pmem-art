美术提需 → 认路 → 出图：全流程（白话版）

给画师看的一张总图：你怎么说需求、系统怎么认成哪一类活、什么时候要问你、什么时候直接画。 电脑匹配用的是字面相近 + 口语对照表 + 一行标准说法，不是「懂意思的 AI 向量」。 红框 / 黄框 = 容易走错、要盯着。

附图不是必须的。 可以只打字（「画一张窗边女孩」）；也可以贴 1 张或多张参考图。
无图 → 多半走「普通图 / 原画 / 界面 / 图标…」里按话术认的那条； 有图 → 还要分清：是锁画风换题材（克隆）、同人换表情（变体）、还是两张图各管一件事（多图分工）。
话说太糊会先问你（例如「那个图标弄下」「昨天那张再来」），不会默默画成普通图。你回一句人话即可。
高风险 · 盯死 中风险 · 易混 主路径 合格线
① 你提需求
大白话说明要什么 · 附图可选
A. 只文字，不附图 完全合法。例：「画一张水彩半身窗边女孩」「做一套主菜单 HUD」。 系统主要靠你的用词认路。
B. 文字 + 1 张参考 要说清参考干什么：锁画风？还是同一角色？还是「照样子换个东西」？ 没说清楚时，默认「有参考；题材不变」→ 普通图，不进克隆。
C. 文字 + 多张图 最好说明每张管什么（脸 / 姿势 / 关开态…）。 两张各管一件事 → 多图分工；没说清楚也会先按普通图兜底或来问你。
  • 你也可以直接点名：/pmem-draw /pmem-ui /pmem-icon… —— 点了名就按点名走，总控不改判。
  • 没点名 → 走总控 /pmem-agent，下面从 ② 开始。
⚠ 高风险 ② 收成「标准说法」一行
Agent 把口语翻译成固定句式（给你看见）
因为匹配看字面，口语要先收成模板句，例如： 有参考图；换新题材；锁画风；走克隆。 这句写错，后面容易认错路——所以会写进分析给你核对。
  • 有参考但你没说换题材 → 不能写成克隆
  • 「镜头感强一点 / 只要一张」→ 不是「镜头包」
  • 「画个图标」没说桌面 / SVG / 背包 → 要问清 A/B/C，不能替你猜
  • 没附图时，标准句里不要硬写「有参考图」
③ 本地认路 route
命令对照：原话 + 标准句（有图再加 --image）
python3 pmem_art.py route --text "你的原话" --canonical "标准说法" · 有参考时再加 --image 路径（可多张）。
规则认路（准绳）主要看你的原话；有图才看图角色。决定走哪条合同。
近邻对照（校准）在话术库里找相近说法，只取前几条，不把整库塞给模型。
⚠ 易混 ④ 看结果标签
结论最前一行你会看到其中一种
【走默认路径】专技没对上，按普通单张画画（medium，最多 4 轮，≥9.5）。
【按 XX 走了】认成某一类：克隆 / 变体 / 界面 / 图标A…
【路由停】说不清或互相打架，先问你，不直接开画。
若标准句和原话规则打架 → plan_conflict，一律当「先问你」。
⚠ 高风险 ⑤ 一轮审核（只审一次）
合不合理、漏没漏、有没有理解错
可默认（不用问）文件路径、对比页版式、「再跑一遍」同范围… 会写成「默认：…」。
硬不确定（必须问）到底 UI 还是插画、题材会画成另一个东西、图标 A/B/C 打架、置信度低…
⑥ 怎么往下走
三种情况
只有一种确定列出分析后直接执行，不再等你点头。
多种可能只列出选项，停住；你选一种后再执行。
你改口另说按新话整轮重审；这一轮先列出来等你确认，不顺手开画。
⚠ 易混 ⑦ 步骤表 → 交给对应技能
一次只走一支；六样写齐再动手
用哪支技能 / 交什么 / 垫哪张图（没有就不垫）/ 锁什么 / 怎样算完成 / 交给下一步什么。
  • 有多张参考：全部带上，不能先合成一张再交出去
  • 无参考：步骤里写清「不垫图」，照样可跑普通图 / 原画 / UI 等
  • 界面、图标集、合成梯：禁止用「随便一张插画」交差
⑧ 画画闭环
最多 4 轮 · 总分要到 9.5 才停
每轮给你看图 + 六维分 + 还差什么。不到线继续改；满 4 轮取最高分那张。展陈页还要过闸门。
结算给你看
标签 → 分析 → 步骤 → 该技能自己的出图报告
总控不另写一套花哨总结。口味会静默记；知识卡要你说「收下」才写入。

认路变体一览（美术对照表）

你大概想要什么 → 系统应走哪条。有图 / 无图都写明。

你想要的 典型说法（有图 / 无图） 走哪条 别和谁搞混
就画一张 无图：「画一张水彩半身」
有图：「参考这张，还是画这个人，别换题材」		 【走默认路径】普通图 有参考≠克隆；没说换题材就别进克隆
锁画风，换个新东西 通常要有参考图：「照这张味道，主体换成一只猫」 克隆 无参考却说「换成」→ 多半还是普通图，或先问清
同一角色换表情/动作/画风 常有图：「同一张脸，再来一张生气的」 变体 不是多图分工；机位身份已在同一张上
两张图各管一件事 要有 ≥2 张图：「第一张管脸，第二张管坐姿」 多图分工 一张图改表情仍是变体
关 / 开 两态 有身份图+结构图：先画关上，再画打开 多图分工（前后两行） 不是变体表情差分
几套机位自己挑 可无成图：「给我三套机位我来选」（点选前不生图） 镜头包 「镜头感强一点只要一张」仍是普通图
主视觉 / 海报气氛 常无图或有气氛参考：「一张概念海报当主视觉」 原画 不是整套 UI
整套界面 / HUD / 九宫格 可无图：「一整套主菜单，按钮要有按下态」 界面 UI 「就一张空弹框」→ 普通图，不升成整套
桌面 App 图标 可无图：「做一枚 1024 启动图标」 图标 A 和线性 SVG、背包格不要混
一套线性 SVG 可无图：「做一套线性 svg 图标」 图标 B 不是 1024 桌面母版
背包道具格 可无图：「256 透明底道具图标」 图标 C 只说「画个图标」→ 先问 A/B/C
合成升级梯 L1–L8 可无图：「这把剑一档比一档大，做合成梯」 合成梯 同框整梯只是预览，不是成品；成品一档一张方图
以后都按这张画 要有样张：「以后按这张色板」 锁风格（不生图） 不是当场出一张插画
只审不画 要有待审图：「只审这张，别画」 审图 「审完再改」会串到审图→再画
先写提示词 通常无图：「先写提示词，先不出图」 提示词 写完若还要画，会串第二步普通图等
散图归位 / 看进步 归档、教练类 归档 / 教练 不进自动生图
系统还不支持的活 局部修手、分镜、设定表、扩画布、逐帧… 【路由停】不改走普通图 不会假装用普通图交差

重点盯梢

位置风险怎么防
① 附图 以为「必须附图」或「有图就一定克隆」 附图可选；有图要说清用途
② 标准说法 口语误译成克隆 / 镜头包 / 整套 UI 给你看标准句；冲突就停
④ 冲突 / 低置信 标准句和原话打架仍硬画 先问你；确认前不生图
变体 vs 多图 vs 克隆 三种最容易互相冒充 看上表「别和谁搞混」三列
⑧ 停机 <9.5 却当终稿 闭环硬闸；展陈再过 showcase-gate

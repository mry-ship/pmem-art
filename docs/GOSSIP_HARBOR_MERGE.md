休闲 merge 没写画风时，渲染气质钉本页；**档序只在玩家点名 GH、或垫图就是它的商店资源时**照抄。通用合同与出图模板见 `/pmem-merge-ladder` 技能与 `docs/MERGE_MULTI_LENS.md`。多游戏真链档序总表见 `docs/MERGE_CHAIN_REFERENCE.md`。

## 渲染气质（缺省）

Gossip Harbor **玩具货柜**（本类休闲 merge 的默认渲染）：**软立体糖釉**道具、圆润厚实、无硬描边、暖饱和、**块面高光**可读、棋盘缩略一眼可认（对标真机棋盘货的休闲图标完成度，不是美食棚拍）。材质是有体积的糖釉玩具货柜道具，不是实物，也不是哑光黏土/软塑胶 UI，更不是平面绘本贴纸。  
整表参考只锁格子版式；禁止写实摄影、美食棚拍、产品静物、玻璃真实折射、木纹指纹、果汁乳浊摄影感、微距毛孔、暗沉旧塑料、油光金属、硬镜面 CGI、皮克斯硬塑胶高光、哑光黏土拟态、软塑胶 UI、平面绘本贴纸冒充货柜。只写游戏名不够，surface / 出图前缀必须带上述禁句。  
**档位句**只写糖釉玩具剪影 / 件数 / 容器 / 完成态；禁止焦斑、烤痕、鳞片微距、湿润汤面感、摄影级摆盘质感词——这些会盖过「不是实物」，让首轮漂成美食图。身份词（如柠檬茶）可以；柠檬片等配菜词在**垫真机截图锁画风**时可跟真机货面，纯文默认仍拦。`relation-judge` 会拦。

### 垫真机 / 截图锁画风（优先于缺省句）
玩家明确要垫 `assets/refs/gossip_harbor` 或「拿真机图垫风格」时：**画风跟截图棋盘货表面**，系统**不再灌**缺省软立体糖釉长句（会与真机货面打架）。宜垫**货条/单格作物**（如龙虾冰碗裁条），整屏截图只作风格参考时须写清「勿抄 HUD/手势/全棋盘」。交付整表仍用浅奶油 4×2 卡，除非玩家点名别的版式。竖屏交付画幅跟竖屏垫图；横条货面不要当 `--ref-image` 主垫去顶 9:16。

# 离线 vs VLM 分差审计（gpt-6-sol）

**结论：** 离线均分落后不是图像普遍只有 5 分，而是把「代理测量失败」当成了「作品失败」：多个指标没有测到合同所要求的语义或结构，却以 0 分计入；再叠加硬封顶和分母重归一，系统性压低维度分。四张样例中 C1、C5、T1、T4 几乎固定报零，正是代理与目标构念不匹配的直接证据。应先修正可判定性、置信度和封顶规则，再用带专家/VLM 标签的留出集校准；不能为追到 7 或 8.5 直接抬基线或强行加分。

## 根因
- **[high]** 不可测代理被当作被测能力的失败证据 — C1 用 3x3 显著性差替代主体识别，C5 用对比度衰减替代遮挡/透视深度，T1 用四象限色度与高频方差替代材料区分，T4 的 mush/coherence 代理却标成边缘融化率。四例中这些项目重复出现 0 分，但它们的指标并不能证明合同项失败。
- **[high]** 缺少语义与场景条件判断，导致系统性误报而非随机噪声 — center-box 不等于主体，边缘密度比不能判定视觉层级或主体对比，contrast falloff 不能区分夜景、雾、景深与透视。样例把夜景和人像都判为主体不明确、前后景弱；这些结论超出了现有特征的可识别范围。
- **[high]** 缺失项重归一与硬封顶放大代理误差 — P1-P4/P6、S1/S2/S6、L1/L6 常为 N/A，剩余项目权重被扩张；而 P5 是唯一透视代理并触发 perspective <=7.5 封顶。short_side<480 还把 T4 设为最高 1，并将质感封顶 5，分辨率被错误当成作品质量上限。
- **[high]** 0/1/2 离散评分与阈值未校准，且缺少不确定状态 — C1 的 salience_gap 在 0.0126-0.0506 间均报 0；C5 的 depth_cue 在 0-0.039 均报 0；不同质量样例因此得到相同缺陷标签。当前数据没有展示这些阈值对应的合同评分边界或误差率。
- **[high]** 少量维度低分主导总分，掩盖可测维度表现 — 两张夜景的光影分别为 6.15 和 8.85、风格为 5 和 7.86，但构图/透视/质感多个低分或封顶使总分仍为 5.04 和 6.15；人像风格为 10，仍被不可测透视的 0 拉到 4.28。

## 检查项误标定
- `C1 主体/视觉焦点`: 网格 salience_gap 测的是显著性集中程度，不是主体是否存在、明确或构图是否有意。群像、城市全景、均匀光线和多焦点设计会被代理结构性判零。 → **改法:** 无分割时将其标为低置信度代理，不能单独给 0 或输出“主体不明确”。结合多尺度显著性、局部对比、中心/三分位布局及裁切压力只产生弱证据；证据冲突或场景可能多焦点时记 N/A/不确定。
- `C2 / L5 / T3 中心框对边缘`: 画面中心不必是主体，边缘也可能有主体或关键内容；边缘密度比不能直接代表构图层级、主体受光或细节分布。 → **改法:** 取消 center-box 等同 subject 的解释。将其保留为布局/空间分布的弱特征，按多区域分位数和显著性位置判断；没有主体定位时这些项记不确定，不生成主体相关缺陷。
- `C5 景深/前后景关系`: contrast falloff 单独不能识别遮挡顺序、尺度递减或透视；0 depth_cue 不等于没有空间层次，尤其误伤夜景、雾景、平面化风格和长焦场景。 → **改法:** 把对比衰减降为单一弱线索。无语义分割时仅在多个独立线索一致时给低分，例如遮挡边界、尺度/纹理梯度、消失线或清晰度梯度；否则记 N/A 或中性，不报“前后景弱”。
- `C6 缩略图可读性`: read_256 的边缘能量不是可读性本身；低边缘能量可能是有意柔焦或大色块，高能量也可能只是噪声。 → **改法:** 将其用于辅助分档而非直接评分，加入缩放前后结构保持、局部对比与噪声惩罚；在代理未验证前采用中性区间并报告置信度。
- `L3 白平衡`: 粗略 Lab 中间调偏差会把有意的暖光、冷色夜景和风格化调色判成色偏；样例 wb_dev 约 18-20 被判 0，但没有中性物或参考目标时无法区分创作意图与错误。 → **改法:** 无中性参考时不得把全局色温偏离直接记为失败。仅对明显通道剪切、局部不一致或与给定参考不符扣分；否则记 N/A/低置信度。
- `P1-P6 透视与结构`: 仅 P5 edge_coherence 可测时，缺失项目重归一会让这个弱代理代表整个维度；以它触发 7.5 硬封顶没有合同依据。最后一例透视为 0，来自单一代理，不能支持“体积/结构相干弱”的确定结论。 → **改法:** 移除仅凭 P5 的维度硬封顶。P5 只作为低权重线索；无可验证几何/解剖证据则维度标低置信度或 N/A，不把无对象场景、风格化透视或非写实构图判错。
- `T1 材质区分度`: 象限间色度/HF 方差测的是区域统计差异，不是不同材料是否有可辨识的反射、纹理或边界。四例中 material_spread 低就报材质不足，属于代理冒充语义判断。 → **改法:** 没有材料区域/对象识别时改为 N/A 或中性分；可用局部纹理频谱、边缘保持和区域间统计作为弱证据，不能据此断言材料混淆。
- `T4 边缘融化`: mushiness/coherence 不是边缘融化长度比，二者也会受绘画笔触、柔焦、低照度与缩放影响。把 mushiness 代理硬写成 melt_ratio 并在短边小于 480 时强制最高 1，是明显的构念错误和分辨率偏置。 → **改法:** 删除当前 melt_ratio 到 T4 的直接映射及短边硬封顶。无边界/轮廓测量能力时 T4 记 N/A；清晰度代理只对可验证的局部结构断裂、非预期涂抹提供有限扣分。
- `短边分辨率与质感维度封顶`: 像素尺寸不等于图像内容质量；405px 短边可在目标显示尺寸下清晰可读。短边阈值把 T4 限为 1 并将维度封顶 5，会无视实际可读性和生成尺寸的用途。 → **改法:** 取消质量硬封顶。若分辨率不足以可靠评估某项，只降低该项置信度或记 N/A；另行报告技术分辨率，不混入美术质量分。
- `S1/S2/S4/S6 风格特异性`: 缺参考图、风格描述或语义识别时无法可靠判定一致性、遵循度与意图；将其普遍记 N/A 后重归一，会让少数 S3/S5 代理不当地代表整个维度。 → **改法:** 明确区分参考条件下可评分项与无条件不可评分项。没有参考时记 N/A，并通过固定合同政策处理覆盖率，不把缺失权重按比例无限放大；不要由色彩丰富度或分辨率替代风格判断。
- `缺失项与维度聚合`: 按已用权重重归一会在高缺失率维度制造虚假精度；零分代理仍以完整权重参与，导致少数误判主宰维度和总分。 → **改法:** 同时输出分数、有效权重覆盖率和置信区间。低覆盖率维度不输出确定点分；不确定项不记 0。校准后按固定可评分权重或收缩到中性先验聚合，并限制单个未经验证代理的维度影响。

## 离线做对的

- 总体结构保留了五维和可审计的逐项权重，便于定位偏差，而不是只给不可解释的总分。
- 清晰度、裁切压力、剪切、噪声和颜色统计可作为技术质量或弱辅助特征；问题在于把它们直接等同于语义质量。
- N/A 的概念是必要的，尤其是无参考条件下的风格一致性；当前主要错误是 N/A 后的重归一和其他代理的过度确定。
- 样例能暴露明确的方向性偏差：固定低分集中在同几项，说明需要先修代理映射与封顶，而不是简单调整全局偏置。

## 建议补丁

1. 撤销 T4 的 mushiness-to-melt 映射、short_side<480 的 T4/质感硬封顶，以及仅凭 P5 的透视维度封顶；这些规则没有与合同构念相符的证据。 （预期：立即消除由分辨率和单一弱代理造成的结构性低分；不会自动抬高真实可测缺陷项。）
2. 为每项加入可判定性与置信度状态：pass/fail/uncertain/not_applicable。C1/C5/T1/T4 以及无参考风格项在代理不充分时用 uncertain 或 N/A，禁止把代理缺失解释成 0 分或确定缺陷。 （预期：减少系统性假阳性，避免把不可测项目伪装成可靠的逐项检查结果。）
3. 重做聚合：报告维度分、有效权重覆盖率和不确定度；低覆盖维度不做简单重归一，也不允许少数代理支配。以专家/VLM 标签拟合并验证固定权重或收缩聚合。 （预期：高缺失维度不再因少数剩余项被极端拉低或抬高，总分能反映证据量。）
4. 对代理项做按场景分层的阈值校准和消融：夜景/人像/城市/插画分别检查 C1、C5、L3、T1、T4 的误报率；使用独立留出集校准等级边界，不用四张样例直接定阈值。 （预期：识别场景依赖误伤，避免用单一阈值惩罚合理的柔焦、均匀构图、风格化色调或平面化表达。）
5. 把 center-box 与边缘密度比改为弱布局特征，取消“中心就是主体”的推断；多尺度区域、局部对比和边缘/遮挡线索仅在相互支持时更新 C2/L5/C5。 （预期：降低中心主体假设造成的构图、主体层级和前后景误判，同时保留低成本可解释信号。）
6. 建立小型带人工双评与仲裁的校准集，并同时报告离线对合同分项及维度的 MAE、系统偏差、误报率、覆盖率和分场景结果；以此决定是否达到合格约 7、优秀约 8.5 的量级。 （预期：把目标分数作为经验证的校准目标，而非通过加分凑均值；能判断离线实现何时真正接近合同量级。）

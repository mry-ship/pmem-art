# 合成梯 · 多维审稿透镜（通用）

Merge 不是「一档比一档更大更好看」。玩家合两下要爽、棋盘上要认得出、货柜上要像同店货。出图前按下面七层过；链型说不通先别出图。

## 0. 对标材料（先决）
- 先看同品类 **真 merge 货柜/棋盘道具**（Merge Mansion / Travel Town / EverMerge 等），不是宣传海报。
- 只抽链型与密度写进关系稿；**禁止垫像素抄物件**。
- 先定 `chain_mode`，再说通 `merge_why` / `parts_add`，再出图。

---

## 1. 合两下体验（玩家为什么合）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 合成预期 | 两件同级 → 下一档，说得出「为何变成它」 | 「更华丽」空话；装饰换装断故事 |
| 犒赏感 | 低档朴素、高档值得炫耀 | 全程同密度；末档反而缩水 |
| 可读进度 | 隔一档也能感到升级 | 邻档几乎双胞胎 |

## 2. 棋盘 / 货柜视觉（缩略怎么扫）
| 问 | 合格线 | 翻车例 |
| :--- | :--- | :--- |
| 64px 邻档可分 | 剪影句不能复读；体量缓增 | 只加光点、小饰片棋盘看不见 |
| 单件居中 | 每档/每格一件，无脸无等级字 | 场景插画、多件堆砌 |
| 同机位组 | 一链同棚灯同仰角（per_cell） | 每档换机位像拼盘 |

## 3. 档位重要程度（稀有度曲线）
1. **L 低**：基础原料/简包装——识别家族基因即可  
2. **L 中**：形态或零件明显升级——`evolve_to` / `parts_add` 肉眼可见  
3. **L 高**：犒赏件——体量最大、细节成块，仍同家族  

曲线要平滑；禁止无过渡跨品类硬跳（糖→奖杯）。

## 4. 链型合同（上下游）
| 链型 | 通用含义 | 禁 |
| :--- | :--- | :--- |
| `shop_ladder` | 同族形变/同店货（主流） | 强行 `base_body`；糖果默锁 `same_object` |
| `same_object` | 同模只加装 | 礼盒/奖杯换货主语 |
| `species_change` | 同任务域换物种 | 用「禁换物种」口味压过「一组 X」 |
| 轻门（省略） | 未点名链型 | **非糖果**勿默锁 `shop_ladder` |

## 5. 颜色与材质
- 锁**家族色相/题材基因**，不是每档换色盘。  
- 介质跟题材：软糖才 SSS；金属/木/陶各写各的。  
- 默认卡通下禁无故产品实拍油光。

## 6. 整体风格套件
- 一句话表面锁死整链；`overview_sheet` 可锁白卡深底版式。  
- `per_cell` 透明或纯黑隔离，勿白卡冒充逐格成品。

## 7. 出图前最小检查
```
[ ] 链型选对；关系门 / 五问已过
[ ] 每档 merge_why 或 parts_add 具体
[ ] 体量缓增；64px 邻档可分
[ ] 家族基因不断；无装饰换装
[ ] 真 merge 货柜思路已看（非海报）
```

## 光影法则

- **主光**：画面左上方柔漫日光，暖白偏奶油，无硬边太阳斑。
- **环境光**：草叶与水洼带青绿/浅蓝冷反射；阴影短、软、可读接触点，禁止死黑。
- **高光材质**：哑光→缎面（树脂/软塑胶玩具感）；水面仅 stylized 浅涟漪，禁止镜面油光与金属闪点。
- **景深**：远景巨型花草轻微虚化，焦点落在前景小屋与庭院。
- **氛围**：童话缩景、饱和友好、休闲 merge / 装修花园顶级商业气质（Merge Mansion / Gardenscapes 级完成度，只抽气质不抄构图）。

## 笔触与渲染

- 软立体 3D / 圆角玩具体量；形体圆润、边缘干净，**几乎无可见描边**（形体靠色阶与光影过渡）。
- 材质分层少而清楚：木质粗纹暗示、菇盖软塑胶、水面半透明浅池；纹理干净不脏。
- 比例：微缩村庄 + 巨型花草制造尺度差；角色为 Q 版小动物，非真人比例。

## 可直接拿去画的完整句子

画一个童话微缩花园村庄：翠绿草叶 `#77B733` 铺巨型植被，铃兰花紫 `#9D55D1` 做花瓣屋顶，暖陶木褐 `#A66B3E` 搭木结构；池水青蓝 `#59B1F5` 与奶油白墙 `#FDF8E4` 做水面与屋体，莓花粉 `#F4889E` 与香蕉金 `#F9C823` 做小锚点。左上柔漫暖白日光、短青绿接触影，软立体圆角玩具感，哑光到缎面，无硬描边、无霓虹、无写实脏暗。

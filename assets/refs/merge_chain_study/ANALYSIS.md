## 跨游戏共同语法（比单游戏更硬）

1. **一档一件完整货**。棋盘缩略一眼能报出货名。
2. **合两下至少换一类**：剪影 / 件数 / 容器 / 完成态 / 物种工具。中段同杯加碟、加糖勺、换花纹合法。只转角度、掏空、挂一颗看不见的配料，不算。
3. **前段朴素完整，后段犒赏**。配料、附件晚出现。
4. **剪影大类邻档可分**。Travel Town 冰淇淋：球→西瓜形→奇异果→彩虹棒→甜筒→更大筒→圣代。Love & Pies 蛋糕：曲奇→短蛋糕→杯糕→切片→芝士→提拉米苏→整蛋糕。
5. **体量可不单调**。Gossip Harbor Decaf Coffee 前 12 档占卡高约 0.83–1.00 且 L4→L5 缩小；分档靠剪影与件数，不靠放大。硬伤只拦末档明显矮于前档。
6. **工具链两派都合法**：
   - Merge Mansion Watering：同功能系统升级（水→壶→水管）。
   - Merge Mansion Gardening Tools：每档换一种完整工具（刀→叉→剪→斧→铲…）。
   禁止「同一把壶贴花到八档」（件数/剪影都不变）。
7. **建造链（EverMerge）**：原木→木料→框架→建筑→屋。半成品只出现在建造过程，不套到食物主流链。

## 压缩到 8 档的金牌曲线

食物饮品：`原料 → 切开/半成品份 → 单人容器 → 更大容器 → 加工态 → 包装/罐 → 单品犒赏 → 套装/盛宴`  
浇水工具：`水/杯 → 尖嘴 → 长嘴 → 莲蓬壶 → 泵瓶 → 背罐 → 水管卷 → 一体喷灌车`  
同族乐器：`短哨 → 直管 → 喇叭口仍在笛上 → 加键长笛 → 排箫一件 → 立管排 → 小风琴 → 最宽最高风琴`

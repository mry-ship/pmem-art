## 零点五、开画前强制 route（与总控同闸；点名 `/pmem-draw` 也要跑）

本技能**不能**绕开路由闸。标准路由句模板、冲突闸与 `execute_ok`/`ask` 语义见 `/pmem-agent` 第零段（此处不重写完整分流）。**任何自拟子合同或 `converge start` 之前**必须：

1. 把玩家原话收成一行标准路由句（模板见 agent）。
2. 跑：
```bash
python3 pmem_art.py route --text "<玩家原话>" --canonical "<标准路由句>"
```
3. 以 `route_ids` / `banner` 写入闸门缓存并锁定子合同；点名锁定不改判，仍须跑 route。
4. 缺缓存时可 `converge start --route-id draw.ordinary|draw.clone|draw.key|…` **点名种闸**（与完整 route 等价放行）。
5. **禁止** `--skip-route-gate` / `PMEM_ART_SKIP_ROUTE_GATE` 偷跑。
6. 点名锁定/口头草稿与 `route_ids` 冲突：停问玩家，禁止硬开画。
7. 判成界面 / 图标 / 合成梯：先留下本次 route 缓存，再读对应技能。

route 锁定后只读注册表该行的 **`pack_headings` 执行包**；不要整份全文串味。镜头包点选前不生图，仍须先 route。

你现在运行在 **pmem-art 闭环自评收敛生图模式**。进入普通图或原画后：**第 1 轮真实评分 ≥9.5 就立刻 finish**，禁止为凑轮次再画；不到线才进入下一轮，最多 4 轮兜底后交最高分并标明「未过线」。

## 二、标准执行流程（Step 1 ~ Step 3）

### Step 1：Warm-Start 召回 & 初始化收敛会话（首轮就要接近 9 分）
1. 记忆召回是自动的，禁止再靠手贴：`converge start` 写入 Warm-Start；`converge generate` 并入提示词；Cursor `preToolUse` 在 GenerateImage 时用 `updated_input` 再灌一次。`search --module` 只在要给画师看召回结果时可选跑：
   ```bash
   python3 pmem_art.py search --module <目标模块>
   ```
2. **启动收敛（自动注入 Warm-Start 包：Top recipes + 红线 + 个人口味）**：
   ```bash
   python3 pmem_art.py converge start --goal "<用户目标描述>" --module <目标模块> [--mode quality|fast] [--scale low|medium|high|recompose] [--recompose-dir "<新构图方向>"] [--ref-image <参考图>] [--ref-analysis "<参考图分析>"]
   ```
   - 默认 `--mode quality` = 合格线 ≥9.5 **到线即停**；最多 4 轮兜底，不鼓励跑满。
   - `--scale`：`low` 贴原修瑕 · `medium` 小优化锁机位（默认）· `high` 大胆跃升+可叙事 · `recompose` 须配 `--recompose-dir`。
   - `--mode fast`：warm-start 置信度高时可走 **fast track**（仍须每张打分；最终采纳默认仍要 ≥9.5，除非用户明确说「草稿/fast/先看看」）。
   - `converge generate` **自动把 Warm-Start `prompt_block` 并入提示词**。Cursor **GenerateImage** 路径上，`preToolUse` Hook 再用 `updated_input` 灌一次。对话里回显「pmem-art 已自动并入记忆」。禁止再靠手贴。
   - **外部生图**（Shell / apikey-image 等、不经 Cursor GenerateImage）：Hook 可能整段不触发——以 `converge generate` 并入的 prompt 为准，开画前确认会话里已有 warm-start / revised；不要把「没跑到 GenerateImage Hook」误报成「没并入就是 bug」。
   - **档位只规定能动多少，出图句用开会话打印的那一家**：
     - `low`：写成一处可改，并点名邻区保持原样。
     - `medium`：只留一处看得见的打磨，机位锁死。
     - `high`：只抬这一媒介已经有的长处。体积光只写进厚涂。**≥2 轮才停**。
     - `recompose`：写出新布局，并写明旧机位作废。**≥2 轮**；未换机位勿停。`--goal` 只锁画风、身份和禁令；姿势和机位只写在 `--recompose-dir`。禁止 goal 里再写旧机位姿态。
   - 同模块已经锁过风格时，第 1 轮提示词带上已锁的 HEX 和禁用词。
   - **最优方向按档分流**（加法，不是第二份锁）。出图前可跑：`python3 pmem_art.py check-scale-gates --self-check`。
   - **不要中途改去镜头包**。玩家没要几套机位，就按当前这一支继续。`high` / `recompose` 缺一句机位时，用玩家已经写的目标或档位骨架，不要停下来提议 4 套镜头。
3. **合理性闸（首轮 generate 前必过，至少一次）**：先写草稿提示词，按清单自审，**同时交出更合理的修订提示词**，再写入会话。不过闸 `converge generate` 会被拦截。克隆/变体/多图分工/原画同样走这一步（`--skill` 用 `clone`/`variant`/`split`/`keyart`）。
   ```bash
   python3 pmem_art.py reasonableness review --id <session> --skill ordinary \
     --draft "<草稿提示词>" --revised "<更合理的提示词>" \
     --checklist "subject_action=ok;contact_scale=ok;element_budget=ok;hard_locks=ok;fail_at_glance=ok"
   ```
   清单模板：`python3 pmem_art.py reasonableness template --skill ordinary`。修订句必须写清：主体动作、接触/尺度、元素预算、硬锁、一眼失败条件。首轮 `generate` **强制使用 revised**（未再审的其他 `--prompt` 会被忽略）；可省略 `--prompt`。非首轮空 `--prompt` 回退 revised。后续审美迭代不得推翻硬锁与预算。调试才允许 `--skip-reasonableness-gate`。
4. **Best-of-N 首帧（默认禁止）**：只有玩家明确说「先试几套方向 / 并行挑一张 / Best-of-N」才开；默认同方向进 R1，禁止自作主张先画 2~3 张再挑。若开了：须在合理性闸之后，并写明选了哪条。

### Step 2：闭环自评收敛循环（到线即停；最多 4 轮兜底；合格线 `>= 9.5 / 10.0`）

令轮次 $i = 1, 2, \dots, 4$：

#### 2.1 生成第 $i$ 轮单张候选图
- 综合「用户原始需求 + 参考图解构特征（若有）+ `.memory-art` 历史红线 + **合理性修订提示词** + **针对上一轮最低分维度的具体修正指令（≤2 条）**」，构造第 $i$ 轮生图 Prompt。首轮必须以 `reasonableness` 的 revised 为底，禁止用未审草稿直接出图。
- **首轮（R1）按主体分类注入结构底线（认不出就不注入，禁止默认塞山体/建筑）**。词表中英两套都用来认主体；写入生图提示词的是英文，中文只在回显里给你看：
  - **人物**：关节、握持、双眼；
  - **动物**：按物种连接肢体，禁止改成人类双肘；
  - **机械体**（机甲 / 机器人 / mecha）：机械关节与接缝，不写人类瞳孔；
  - **`character.*` 但没写物种**：只写主体轮廓连续，不套人类关节；
  - **纯场景**：只写灭点与接触阴影；
  - **任务型 UI**（模块 `ui.` / `icon.`、HUD、UI kit、九宫格、图标集）不注入。button / menu / icon / 界面 / 按钮 / 菜单单独出现才算 UI；和人物、动物或场景写在一句里时跟主体走。
  - 「画一张漂亮的图」这类认不出的 brief：**不注入**。
- **垫图**：
  - `low` / `medium`：每一轮都垫最初的参考图。多张图时垫宽高比对齐交付物的那张，其余图留在会话列表里。
  - `high` / `recompose`：机位还没换时垫最初那张。机位已经换过之后，下一轮垫换过机位的最高分那张。
  - 没有参考图的纯文本任务：不垫成图，只在提示词上追加改点。
  - 定稿写死底：实色、场景，或透明。透明交 PNG。品红块和品红底 JPG 不能当交付。
  - **风格跳跃（`recompose_bold` / `style_jump`）**：不垫旧风格参考，也不垫上一轮成图。剪影和画幅留在提示词里。
- 调用生图工具（如 `GenerateImage` 或项目配置的生图脚本）**生成 1 张图**。

#### 2.2 看图打六维（各 0–10；程序按媒介家族算加权调和平均，不要手填总分）
生成后亲自看这一张，缺陷和六维同一遍写完。六维是构图、光影、透视、质感、风格、无瑕疵。无瑕疵跟另外五维一样盲评，打 0–10，不另写瑕疵清单。禁止把上一轮 defects 原句贴过来。本轮缺陷必须写这张图上看得见的部位。`recompose` 缺陷第一句必须回答：仰还是俯、人占画面大约多少、主光从哪来（方向/色温；例句如窗光或灯笼，不是只能二选一）。`high` 必须写明相对原图多出来的那一处光影或叙事；写不出来就把构图当贴原打。

开局用 `--medium-family` 归一次媒介（平涂、像素、赛璐璐、干性、线描、水性、厚涂、摄影、立体、拼贴、自发光，对不上就 `generic`）。后面四轮不改。权重在代码里按这一家取，四档共用一行。画师说「构图松一点」「光影锁定降到 40%」时，锁定表听画师的，压过默认。

正式分是加权调和平均。某一维特别低时总分会被拉下去。点名的部位没改到，或锁住的邻区被整张重画洗掉，9.50 也不能停。

- **构图**：景别、主体占比、重心、前景压角、机位是否按档锁住。
- **光影**：主光、轮廓光、环境反射、接触阴影。平光交给无瑕疵盲评，不另设封顶。
- **透视解剖**：肩肘腕连续、握持受力、五指、双眼同向同高、头身比、脚落地。人物、动物、机械低于 **7.5** 不能停。像素、Q 版、平涂、水彩也不把这条线打折。
- **质感**：媒介对上、布料、金属、头发。噪点不是纸纹。
- **规格**：发色、瞳色、标志配饰、性别年龄、画幅。low 不改机位和姿态。high 必须看得见加了一处。

- **动物**：肢体按物种连接，不出现人类手肘，不按人类瞳孔打分。门槛仍是 7.5。
- **机械**：关节、接缝、外壳咬合。不打人类瞳孔。门槛 7.5。
- **纯场景**：灭点、建筑消失点、近中远空气透视、接触阴影。透视数字交给调和平均。只有缺陷写了结构塌缩或融化才不能停。不套 7.5。

特殊媒介按自己的尺子打那一偏低的维，不要拿写实厚涂当满分。断肢、融化、多手、结构塌缩不能停。平光、呆板、贴原、照搬、缺乏飞白/飞白不够、数字化噪点|痕迹|滤镜写进缺陷且总分仍想过 9.0 时，程序硬顶 ≤8.90（像素/平涂/水彩等媒介按 STYLE_INFLATION_IGNORE 豁免其合法词）；否定句与「已解决」不误杀。

- **像素**：光影和质感按色块、网格打。方块关节还连着仍按 7.5。
- **Q版 / 二头身 / 三头身**：头身比按设定打，不按七头身扣。连接、五指、双眼仍严。门槛仍是 7.5。
- **平涂 / 矢量 / 赛璐璐**：平光是媒介。光影看色块边界和接触阴影，不按体积光扣成不合格。糊成一片才低。门槛仍是 7.5。
- **水彩 / 水墨 / 速写 / 粉彩**：纸纹和飞白不是数字化噪点。边缘松可以，结构塌了不行。门槛仍是 7.5。
- **剪影 / 剪纸**：不按内部体积光和写实解剖扣。外形断了、肢体数量错了仍是硬伤。门槛仍是 7.5。
- **变体**：只改点名的那一项（表情、动作或画风），身份留住。
- **克隆**：新主体，不要把参考里的人再画回来。虹膜加高光，不要黑点瞳孔。主体回声：正式分不超过 8.85，不能停。

示例：`构图8.6/光影8.2/透视7.8/质感8.0/风格8.4/无瑕疵8.0`。旧加和尺 `风格2.2/结构2.0/光影1.7/合规1.4/还原1.3` 仍按相加解析。

#### 2.3 记录到收敛器（生图和审图必须分两步）
```bash
python3 pmem_art.py converge generate \
  --session <id> --round <i> --image "<图片路径>" --prompt "<本轮 Prompt>"
python3 pmem_art.py converge judge \
  --session <id> --round <i> --image "<图片路径>" \
  --dims "构图8.6/光影8.2/透视7.8/质感8.0/风格8.4/无瑕疵8.0" \
  --strengths "<亮点>" \
  --defects "<缺陷，具体到部位>" \
  --next-fix "<下一轮要改的正向描述>"
```
不要把 `--score` 当成最终分。六维解析成功后，停机分是加权调和平均。会话里有多张参考图时，打分前把成图和每一张并排看：构图和透视对上锁机位的那张，身份对上锁身份的那张。不能只看垫进去的那一张就给分。

#### 2.4 向用户展示本轮审图卡（默认必做）
在继续下一轮或进入结算前，把本轮结果写进对话（除非用户 `--quiet`）：
`第 i 轮 · 总分 X.XX · 六维… · 不足：… · 本轮/下轮改点：…`，并附上本轮图。

#### 2.5 收敛判定（核心规则！）
- **情况 1：本轮正式分 `>= 9.5`、已满本档 `min_rounds_before_stop`（`high`/`recompose` 默认 ≥2 轮），且门槛维都过线**
  🎉 **合格达标！** 结束生图循环，以第 $i$ 轮为胜出图，进入 Step 3。
  - **门槛**：人物、动物、机械的透视解剖 `< 7.5` 时，正式分改取这一维，不能停。纯场景只在缺陷写了结构塌缩或融化时不能停，不套 7.5。缺这一维仍然 fail-closed。看板另列「总分≥9.5 且解剖≥8.5」。下一轮改点若是「加强氛围 / 提升体积光」这类空话，由回流策略改成 ≤2 条部位级修正。
- **情况 1b：分数够但未满最小轮次** → 视为未停机，按 `best_direction_hint` 继续叠加（防 1 轮贴原虚高）。
- **情况 2：本轮评分 `< 9.5` 且 $i < 4$**
  🔄 **不合格！** 必须把本轮最低分维度的具体硬伤转化为 **≤2 条部位级修正指令**（如具体关节/持物连接、接触阴影、边缘描边），并入第 $i+1$ 轮 Prompt，**严禁**堆砌「加强氛围、提升体积光」等空泛套话；若本轮评分解析失败，先重试 1 次，仍失败则保持上一轮有效缺陷与底图，绝不用套话污染 Prompt。未 `judge` 不能开下一轮，`finish` 会失败，Cursor stop hook 也会把对话打回来，直到 ≥9.5 或满 4 轮。
- **情况 2b：掉分/平台早停（默认从第 2 轮起可触发）**
  🛑 从第 2 轮起：相对历史最高掉 ≥`0.15`，或连续平台无提升，安全早停并交付历史最高分那张（禁止为凑满 4 轮继续垫掉分图空转）。`high`/`recompose` 仍可在阈值内大胆改，但掉分早停同样生效。
- **情况 3：已满 4 轮（$i = 4$）且评分仍 `< 9.5`**
  🏁 **达到 4 轮上限，停止循环！** 从第 1 ~ 4 轮中**挑选综合评分最高的那一轮图片**作为最终交付图，进入 Step 3。

### Step 3：结算最优图 & 自动沉淀记忆（默认展示评分履历；记忆写入仍静默）

循环结束后，运行：
```bash
python3 pmem_art.py converge finish
```
该命令会自动：
1. 选出达标轮次（`>= 9.5`）或全阶段最高分轮次（`Best of 4` / 安全早停后的历史最高分）。不到 9.5 且未满 4 轮、也未触发安全早停时，禁止把这一张当展陈终稿，也禁止把 r1 复制成 `final.jpg`。
2. 将最终胜出图通过 `ingest` / `feedback` 写入 `.memory-art` 的 `recipe`（正向定稿锚点），并把迭代过程中暴露的典型不合理点写入 `style_redline` / `visual_correction`。
3. 生成并**默认打印**标准 Markdown 评分履历，同时写出可点开的过程板 HTML（只要一行结论时加 `--quiet`，过程板路径仍给出）。
4. 收展陈页前跑 `python3 pmem_art.py showcase-gate --html <index.html>`。有格 < 9.5 且未满 4 轮、也未标安全早停，这一页不能交。

**开跑缺风格（商业气质默认，可默认不必再问）**：玩家未点名画风且无风格参考时，首轮 revised / goal 必须写清**同品类顶级商业完成度气质**一句。先查 `docs/COMMERCIAL_BENCHMARK.md` 按品类填一句（例：休闲三消道具棚拍 / 上架 Key Art / 软塑胶 merge 货柜 / 写实立绘棚拍 / 扁平产品插画——**按题材选，禁止一律套软塑胶 merge**）。只抽气质与密度，**禁止**垫竞品截图像素。有玩家风格句、风格样张、或模块已锁 style-lock 时跟已有锁，不另套泛默认。关系/布局已对标商业时，风格不得回落成无关泛卡通插画。克隆/变体有参考画风时本条不覆盖参考锁。

**终稿拿不准时（商业对标诊断）**：终稿自己拿不准、六维 borderline、或满 4 轮仍心里没底 → 先找同品类顶级商业范例并排对比，定性是理解问题、合理性问题，还是完成度/画风问题，再决定改 brief、改闸或继续收敛。**禁止**把商业范例当垫图抄构图 / 抄机位。结算总结里写清：对标了哪类、诊断属哪一类、下一步动哪一层。

**对用户的默认展示（过程可见 · 记忆写入静默）：**
每轮 `converge judge` 之后，在对话里写本轮审图卡（用户说「安静/quiet」或 CLI `--quiet` 才可省略）：六维分、总分、不足、下一轮改点。
`converge finish` 会写出一张可点开的过程板 HTML。结算时按这个顺序给玩家：
1. **参考图分析**（有参考才写）：构图机位、色板光影、要锁的身份、不要继承的部分。
2. **每一轮出图**：图、六维、总分、这一轮相对上一轮改了什么、还差什么。
3. **过程板**：把 HTML 路径给玩家。板上每张图都能点开看大图，胜出轮有红框。论述稿和出图轮都在这一张板上。
4. **总结**：胜出哪一轮、总分、留下的那一处不足；若触发了商业对标，附诊断结论。
有多轮论述（合成梯关系稿）时，每一稿都要先记，不能只留在对话里：
```bash
python3 pmem_art.py converge discuss --round <稿次> --prompt "<这一稿正文>" --defects "<没过的行>" --next-fix "<下一稿只改哪里>"
```
报告**最底部**必须带档位合同脚注（`converge finish` 已打印），原样转述，例如：
> **目前是 LOW 档**… 若画师说「构图松一点」，表上该维显示 **`75%（默认95%，-20%）`**（档位仍是 low，只微调这一维）。
画师可写：`构图松一点` / `光影锁定降到 40%` / `升到 medium`；Agent 应跑 `converge lock --lock-text "…"` 再继续生图。
💡 若 CLI 打出一行「小提示」，原样转述（每会话最多 1 条）。
**禁止**旁白「正在写反思 / 更新 taste / 入队 learn / 沉淀红线」——记忆仍在 `finish` 后台静默完成。
improve/coach/learn 推销仅在用户主动要时再给。

### Agent 后台（对用户不可见）
`finish`（默认写记忆；`--no-apply` 可跳过） 已自动：写 recipe/红线 + 会话反思 + `run_silent_autopilot`（更新 taste、强化配方、悄悄 enqueue 1–2 条 learn 建议）。距上次巡检 ≥24h 时还会后台懒跑记忆医生（只出报告，不改条目）。

### 闭环总览
`装上就用 → 先认类型 → 画 → 每轮摊开评分与改点 → 偶发一行小提示 → 记忆后台变强；只要终稿用 --quiet；进阶偷看用 /pmem-coach`

## 合同 · 克隆

只在类型是克隆时执行。轮次用第二节的 `converge generate` / `judge` / `finish`，最多 4 轮，合格线 ≥9.5。不要按第一节继承参考构图。禁止无六维数字宣称通过。默认锁大约 95% 的画风，换的是题材。

- **没有参考**：只靠 brief 和自写风格圣经。媒介必须在 brief 里写明。
- **有参考**：每一轮都垫最初那张风格参考。比例、眼型、描边、文案的修正写进提示词，不要垫上一轮成图。禁止事后拿无关图当原图对照。

**锁**：媒介、色板角色、光感、材质语法、红线。按类再加：

- 场景 / 原画：锁媒介和光感，构图可以换。
- **界面弹框母版**：锁媒介和双层描边（参考有两层就把两层都锁住）。新题材是空内容的九宫格面板：中心大块留白，角区不放复杂纹样。禁止把参考里的道具（如礼盒）放进内容区。顶栏纹样最多 1 个。底栏只用符号钮。没有 brief 就不造可读界面文字。参考若是道具图标，分析里写明「只借材质描边，不借布局和主体」。整套组件仍走 `/pmem-ui`，克隆只交一张母版。内容区回声了参考主体 → 压分并且不可停。
- 图标：锁外框、材质、背景习惯。主体是新的。纹样最多 1 个。缩略轮廓要清楚。搪胶、软塑胶体积只在参考本身是玩具或 Q 版时才写。
- 角色：脸的画法跟参考媒介。通用只锁双眼分穴、虹膜、巩膜月牙、高光，禁止独眼和黑点瞳。软颊、短粗肢、大头桶身只在卡通或 Q 版参考里才写。换装可以，禁止三视图。角色身份不是名人脸或著名服装。

**不锁**：构图、题材、身份，除非玩家要求保留。尺寸按玩家说的来，否则跟参考。

风格圣经从参考像素归纳媒介、色板、描边。参考是道具图标时，禁止把道具外形写进界面 brief。界面 brief 写清空内容弹框、禁止中心纹样、符号钮。

六维是 `构图/光影/透视/质感/风格/无瑕疵`。构图分同时看有没有把参考题材抄回来。缺陷写了抄回参考主体、礼盒进了内容区，压到 8.85 以下并且不能停。≥9.5 且结构门过了才停。主参考是黑点瞳而合同要虹膜时，写死虹膜，禁止为了贴参考改回黑点眼。克隆只垫风格那一张。另一张锁机位或身份时，改走多图分工。

交付时对照的是这趟真正垫过的参考。

## 记忆静默 / 履历可见（Agent 必读）
- `converge finish` 后系统**自动**写反思、更新 `taste.json`、强化 recipe/红线、悄悄排队 1–2 条知识建议——**无需**再跑 `/pmem-coach`。
- 对用户默认展示：**参考图分析 + 每轮六维与总分 + 可点开的过程板 + 总结**；记忆写入不要旁白。
- 用户要安静出图时用 `--quiet` 或说「只要终稿」。想看进步、短板或知识卡时再用 `/pmem-coach`。

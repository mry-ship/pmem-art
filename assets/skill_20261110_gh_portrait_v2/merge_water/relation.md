# 庭院浇水八档 · 对标 Merge Mansion Watering（禁书包）+ 渲染钉 Gossip Harbor

链型：same_object（同功能浇水系统）。过程类型：水→壶→水管喷头。
**禁止**背负式喷雾罐、书包、农药背桶、壶焊轮架。

对标 MM Watering 真链压缩：水滴/杯 → 小壶 → 中壶 → 大莲蓬壶 → 更大莲蓬壶 → 水管卷 → 摆动喷头 → 旋转喷灌。

# 庭院管乐八档 · 对标 GH 咖啡「容器换代」语法（同族形变）

链型：species_change（乐器整表，但仍按同店管乐完成态递进，禁止乱跳）。金牌曲线：
短哨 → 直管 → 喇叭口长笛 → 加键长笛 → 排箫一件 → 立管排 → 小风琴 → 最宽最高风琴。

| 档 | 货 | 两件上一档为什么变成它 | 剪影 |
| :--- | :--- | :--- | :--- |
| 1 | 短木哨 | — | 最短管 |
| 2 | 直木笛 | 两只短哨接成更长直管；无喇叭口、无键。 | 细长直管 |
| 3 | 喇叭口长笛 | 两只直笛合成一端喇叭口仍在同一根笛上。 | 直管+喇叭口 |
| 4 | 加键长笛 | 两只喇叭口笛首次加出清晰凸起的圆键盖（至少三颗可见）。禁止贴纸式扁键。 | 笛+凸起键 |
| 5 | 一件排箫 | 两只加键笛换成一排渐高短管焊在同一底板；整件货。 | 阶梯短管排 |
| 6 | 立管排 | 两件排箫换成几根更高立管排在底座上；比第5档明显更高。 | 高立管排 |
| 7 | 小庭院风琴 | 两排立管合成带琴键台的小风琴；比立管排更宽。 | 风琴箱+键台 |
| 8 | 大庭院风琴 | 两台小风琴合成更宽更高的大风琴；管簇必须高于第6档立管，也高于第7档。全图最高最宽。禁止散件。 | 最宽最高风琴 |

主体框高：0.38 / 0.46 / 0.54 / 0.62 / 0.70 / 0.78 / 0.86 / 0.96。
硬闸：第8档货高 > 第6档；第4档键盖必须可认；禁止末档矮于中档。

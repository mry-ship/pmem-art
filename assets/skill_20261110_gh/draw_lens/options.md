# 镜头包 · 窗边写信的花园小妖精

【按 镜头包 走了】 · `route_id=draw.lens`

画风句：Gossip Harbor 式光泽卡通 3D，圆润，无硬描边，暖饱和，不抄竞品角色。

主体锁定：一位原创花园小妖精坐在木窗边写信。四套只换景别、机位和光。回 **A / B / C / D** 后再出图。点选前不出图。

## A · 窗内眼平中景

花园小妖精坐在木窗边低头写信，中景收到腰以上，镜头在眼平、从她左前方约三十度看侧脸和信纸，左侧窗光暖金铺在圆脸上，右侧留一圈柔阴影。

## B · 肩上俯看近景

近景收到双手、羽毛笔和信纸，镜头升到肩上方约一臂、俯约三十度对准笔尖，窗光从画面右上斜切过纸面，暖金高光落在纸心。

## C · 室内对角全景

全景看见整扇花园窗和窗下小桌，镜头退到房间对角、比她头顶略高并轻俯约十度，午后暖光从窗外铺满桌面，小妖精坐在画面左侧。

## D · 窗外低机位中近景

中近景停在窗框里的上半身，镜头在花园外侧降到窗台、透过玻璃略仰约十五度，窗外逆光把圆润轮廓打成暖金边，室内一小盏暖白补在信纸上。

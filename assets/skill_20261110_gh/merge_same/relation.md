# 青瓷园艺喷壶 · same_object 整表（第 1 稿）

chain_mode=same_object。过程类型=同模加装（母体不换，零件累计）。levels=8。delivery=overview_sheet。grid=2×4。

同一把青瓷园艺喷壶，八档只加装不换物种。提梁和壶嘴每档都在，禁止画成圆茶壶。壶腹是拉长的椭圆园艺壶，不是圆肚茶壶，也不是侧把水壶。

档序：素壶、壶嘴加环、叶贴、领结、双嘴、铜泵、玫瑰淋头、节庆雕花壶。体量逐档变大。后档仍看得见前面的零件。玫瑰淋头是壶嘴上的圆形多孔喷头，不是一束花。

## 商业对标

过程对标同模加装药瓶：空瓶→塞→环→托（母体不换，`MERGE_MULTI_LENS` §8.B）。完成度对标 Merge Mansion 货柜：低档已是完整素件，铜泵、玫瑰淋头、节庆雕花只在后段。园艺工具「手套→铲→剪」是换物种，不拿来当本链档序。不自编假竞品名。

## 画风

surface：光泽卡通 3D、圆润厚实、无硬描边、暖饱和、柔光渐变。垫图只锁这层光泽，不锁棋盘、龙虾、英文和标志。整表是深灰底上的 2×4 白圆角卡，无文字，道具无脸。

## 五问

1. 同域同母体。过程类型是同模加装，不是换物种。对标是药瓶加装真过程，不是自拟假档名。surface 跟玩家写的光泽卡通 3D。
2. 无回退。提梁和壶嘴从 L1 就在，后面只加零件，不拆母体。
3. 无缺过渡的大跳。末档仍是这把喷壶，不是城堡或别的容器。
4. 缩略约 64px 能分：环、叶、领结、第二嘴、铜泵、淋头、雕花剪影不同。L1 已是完整素壶，铜与节庆晚出现。邻档体量只大一圈。
5. 升级理由是具体零件累计。两件同级合成下一档 = 焊上表中的下一件零件。

# `/pmem-clone-image` — 画风克隆 → 新图（强制 8 轮 · ≥9.6）

> **最多 8 轮 · 合格线 `≥ 9.6 / 10.0` · 未达标叠加修正 · 满 8 轮挑最高分 · 评分总表**。  
> **禁止只生一张就交差**（除非第 1 轮真实严苛 ≥9.6）。**禁止无五维数字宣称 PASS**。

Default lock **~95%**。可选四档 polish 仅在达标后。

## Modes
- **Mode A（零参考）**：仅 brief + 自写 bible；medium 必须 brief 写明。
- **Mode B（有参考）**：**必须** `reference_image_paths=[风格参考]` 每轮都垫；锁 medium/chrome/眼部语法，**换新题材**；禁止事后拿无关图冒充「原图对照」。

## 合同（~95%）
**LOCK**：medium；色板角色；光感；材质语法；红线；按类：
- Scene/原画：medium+光感；构图自由
- UI：chrome 分层（外框+内描边若参考有则**两层都锁**）；文案=brief；奖励物无脸除非 brief 要求
- Icon：构图框+材质+BG 习惯；主体新；motif≤1；缩略轮廓清晰。vinyl/软塑胶体积仅玩具或 Q 版参考；写实、像素、金属、赛博禁止套 vinyl
- Character：通用只锁双眼分穴、大虹膜+巩膜月牙+高光、禁独眼/黑点瞳。软颊、短粗肢、大头桶身仅卡通或 Q 版；写实或像素参考写该参考的头身，禁止改成玩具比例。换装/身份自由；禁 turnaround
**FREE**：构图/题材/身份（除非要求保留）
**Hard**：Mode B 必须垫参考；motif≤1；尺寸硬锁；禁无 brief 造 UI 字；角色 DNA≠名人脸/著名服装

## Size
用户 W×H → 每轮一致；否则跟参考；AR 不符则 Pillow 锁后再评。

## Step 1：圣经 + Brief
bible（角色写清眼/颊/肢）+ 新题材 brief（UI 精确文案）。Mode B bible 必须从参考像素归纳。

## Step 2：闭环 i=1…8
### 2.1 生成
Prompt = bible + brief + 缺陷叠加 + negatives；Mode B 每轮带风格参考。
**Refine pad**：比例/尺度是主缺陷时**不要**再垫上一张结果（会锁死 bug），只垫风格参考并写绝对相对尺度；chrome/文案缺陷可垫上轮胜出+风格参考。
角色职业信号优先：空手数 T-pose + 胸章/腰带/脚边道具；手持物易缩水，若必须手持则每轮重申绝对尺度。

### 2.2 五维（五个数字，每维 0–10 分加权合成 10.0）
统一传入 `--dims "构图X/光影X/透视X/质感X/风格X"`（兼容旧 2.5/2.5/2.0/1.5/1.5 加和制）：
1. **构图**（结构与题材/新颖度反回声）
2. **光影**（光感与明暗冷暖）
3. **透视**（主体比例/解剖/角色双眼分穴/道具尺度）
4. **质感**（材质语法与边缘，UI 边角 crop 确认双层描边）
5. **风格**（~95% 色板角色与媒介锁定）

### 2.3 判定
≥9.6 停；否则 Overlay 至满 8；满轮 Best-of 标明未达线。

### 参考眼语法冲突
若主参考是黑点瞳，但合同要求虹膜：可辅垫同族虹膜样张，并每轮写死虹膜配方；**禁止**为贴参考把 LOCK 降成黑点眼。

## Step 3：交付
胜出图 + 评分表 + bible 摘要。对照=**本趟真正垫过的参考** | 结果。

## 稳定性门
连续 **3 组**（icon+char+UI 等）全部 ≥9.6 才算稳；失败→通用规则写回（禁写死本次专名）。

## Anti
首发免评 · 假对照 · 100% 死锁布局 · 造 UI 字 · 黑点眼/独眼躲串味 · 个例写死

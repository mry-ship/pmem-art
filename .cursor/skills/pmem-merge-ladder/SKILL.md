# `/pmem-merge-ladder` — 同域合成梯

## 怎么用（复制即用）
```text
/pmem-merge-ladder 青瓷药瓶合成升级梯：空瓶→塞→半药→满药→签环→金托→晶冠→罩瓶；切面玻璃+暖金饰统一画风；先 3 稿文字定关系，再说通再一档一张正方形
/pmem-merge-ladder [附风格参考] 同域沙滩糖果八档，锁参考表面质感，不抄参考物件；允许换物件，类型相似即可，每件用自己的本色和材质；格子里体量只轻跳
```

一条合同。交货是八张正方形。生成必须按组交给生图模型，不要一档一张散跑。

交付物是八张同样大的正方形，每张只有一件、居中。关系过了之后，整组用一张 16:9 画布交给生图模型，画布里排 **8 个相同大小的正方形格**（2 行 × 4 列，格与格一样大；16:9 上下可留灰边）。同一机位、同一画风管线、同一棚灯方向。共享的是镜头和灯，不是色相、不是材质。每件必须完整落在自己的正方形格内，四周留白，不贴边、不穿格、不被裁切。每格按该档 `look` 画那一件自己的本色和材质。这张组图只作体量预览和生成手段，不是展陈成品。按这些正方形格切开才交货。切线切进邻件或把花、鱼、蛋糕切掉，那一档作废，只重出那一档。

## 风格（第一段写死一句，第二段照用。只取一条）

1. 玩家写下了风格，就用写下的。
2. 没写风格但有参考图：先跑 `python3 pmem_art.py ref-read <参考图路径>`，把看见的表面写成一句。底是透明的，不要写成黑底。小高光不要写成油亮。表面光洁，不要改成毛毡或纸纹。不要把参考图文件垫进生图。不抄参考里的物件。
3. 风格和参考都没有：默认从顶级 merge 休闲竞品里取一种棋盘图标语言，任选其一写死——Merge Mansion、Travel Town、Merge Dragons。风格化卡通 3D 棋盘道具，圆润可读，缩到 96px 仍能认。**不是产品实拍，不是写实静物。** 轻微 3/4 居中，浅灰格底短接触影。每件用该物件自己的本色和材质：金鱼就是橙红鳞和双尾，玫瑰就是红瓣绿叶，软糖就是软糖。禁止白模、黏土同色罩染、整组刷成一个色相。道具本身无脸，除非玩家要求有脸。没写明玩具、Q版时，生成前剥掉 vinyl、chibi、搪胶、桶身、金琥珀双描边。

产品实拍、8K 食物摄影、野生动物写实、油光不锈钢微细节要重扣。只有玩家或 brief 明确写实才允许写实。八档不能画成差不多大的棚拍成品。Travel Town 口香糖机把 Sweet Candies、Chocolates、Sprinkle Cakes 分成三条链；糖果链不要焊进蛋糕链。

## 第一段 · 升级链与画风（3 稿，先不出图）

这一段不是跑图。固定 **3 稿**，不再拉到 8 稿。3 稿里定清三件事：八件升级链说不说得通、家族锁（类型必填；颜色不是必选项）、每件自己的本色材质、画风用哪一条。3 稿里没有一稿把下面八条都说通，并且画风已经写成一句，就停在这一段，一张图都不出。

每一稿写成八行，再加一句画风。交给独立文本判断。判断要指出没过的是哪一行、哪一条，画风有没有定死。没过只改那几行或那句画风，已经说通的锁住。不写「不要画某件」。第 1 稿先把升级链和画风都写上。第 2、第 3 稿只补还说不通的升级理由和还没定死的画风。画风按上面「风格」三条里的一条写死。

每一稿立刻记入会话。finish 的过程板按稿次列出这些论述，不能只留在对话里。第一段开始前先 `converge start`，这一段还不出图。

```bash
python3 pmem_art.py converge discuss --round <稿次> --prompt "<这一稿八行>" --defects "<没过的是哪一行>" --next-fix "<下一稿只改哪几行>"
```

八条都要过，而且要说得通：

1. 正好八件，`level` 为 1 到 8。同一合成路线。不许串成无关杂物，也不许把一条链刷成同一色来冒充家族。
2. 每一档画面里将只有一件、居中。不是一对，也不是一组场景。无脸，无等级字。
3. 两件相同的这一档合成下一档。下一档仍是一件，但**可以换成另一个物件**。L2–L8 必须写 `merge_why`：两件上一档为什么变成这一件、相似性在哪。类型相似就够，不必再要求颜色相似。换成一个无关物件，没过。
4. 对标商业 merge-2（Merge Mansion 蛋糕链 Cupcake→切片→巧克力蛋糕→芝士蛋糕，颜色材质都换；异种植物链仙人掌→龟背竹→兰花→大王花；园艺工具链；Travel Town 甜点咖啡）：棋盘**共用一格**，体量只轻跳。L1 建议 0.56～0.62，L8 建议 0.74～0.80。L8−L1 在 0.12～0.24。不要把 L1 画成格里一粒米，也不要把八档画成差不多大的棚拍。相邻档主要靠物件特点认出，不是靠体量夸张，也不是靠同色。
5. 沿档位剪影更复杂或换成更完整的下一件。`parts_add` 必须是这一档新物件的具体零件。`look` 必须写这一件自己的本色+材质+辨认零件（金鱼橙红双尾，不是青绿黏土鱼）。只写「更华丽 / 加光 / 特效」没过。同模只加特效没过。白模、同色罩染没过。
6. 相邻两档的剪影家族不能相同，也不能只改一两个字冒充不同。
7. 家族锁：`family.type` 必填。颜色 / 形态 / 风格可选。**类型相似就够锁链，不用颜色再相似。** **允许换物种。** 每件必须符合该物件自己的特点。禁止把链锁成「同一物件反复加零件」。禁止为了凑两项去写 hue 再把八件刷成同一色。
8. 档位职能（对标商业链，可按题材定名）：L1 入门件（套件里最简单、已能认类型）→ L2–L3 换件（换成下一件相关物）→ L4–L5 职能件（同套件里更完整的工具/食物/生物）→ L6–L7 稀有件 → L8 展陈件（链上的英雄件，仍是一件）。

机读数字过了、合成说不通，仍然不算定稿。讨论定稿之后，才把这八行写成机读文件。文件要有 `tracks:`，并含 `family`（必有 `type`）。每一行用这些英文键：`level`、`name`、`silhouette`、`scale_delta`、`scale_pct`、`parts_add`、`look`、`merge_why`、`role`。`look` 是这一件自己的本色+材质，八档不得雷同、不得整组写同一个色名。`scale_pct` 单调递增（L1 0.52～0.64 且建议 0.56～0.62，L8 0.70～0.82，跨度 0.12～0.24）。新任务默认用 0.56 / 0.59 / 0.62 / 0.65 / 0.68 / 0.71 / 0.74 / 0.77。L1 的 `parts_add` 写 `—`，L2–L8 必须是具体零件且有 `merge_why`。键名写错或少了 `scale_pct` / `family.type` / `merge_why`，`relation-judge` 审不了。

新任务另写一份副本，照 `docs/showcase/skill_full_modes_1027/merge_phase1_canonical.yaml` 的结构。不要改掉这份 canonical 里已有的 track。然后必须跑：

```bash
python pmem_art.py merge relation-judge --file <yaml> --all
```

**exit 0 才能出图。** 3 稿仍不过，停在这一段，不进入第二段。

关系过了，按组交给生图模型跑一张 16:9、内含 8 个相同正方形格的组图，再按正方形格切开核对。对不上就只改那一档，不重选八件。然后跑 `merge audit`。没过可以 `merge normalize` 一次再 audit。仍不过就只重出坏格，不要靠归一化交差。audit 没过，不能进第二段。

```bash
python pmem_art.py merge split-sheet --sheet <组图> --dir <方图目录> --rows 2 --columns 4
```

## 第二段 · 美术

只从第一段过关的正方形接着画，不重选八件。第二段若要改画风或锁一致性，仍按组重出整梯格再切；只修一档才单独重出那一格。最多再 4 轮，合格线 ≥ 9.6，`converge start --scale medium`。表面那一句每轮原样保留。生图句不写光影张力、体积光、次表面散射。件数、顺序、档位大小继续锁着。

关系是单独一道门：同一路线、相似性还在、每档换成下一件、一句画风、无脸、无等级字。关系没过就不能出图，也不能靠美术分停。每一档的美术分用图标 C 的加权调和平均（剪影、描边色板、棚拍光和无瑕疵进平均；透明底和无字只做门槛）。只变大、物件没换成下一件，不能停。关系散了，美术分再高也不算过。

同一档继续修时，每一轮垫的是这一档第一张关系过关的正方形，只在提示词里改点名的那一处。不垫风格参考文件，不垫上一轮更高分的成图，也不把前几轮修正叠进同一段。

每轮先出图再看像素。向玩家写出六维分、不足、下一轮改点，并再查第一段的关系。第二段每一轮 judge 之后再跑一次 audit。关系还在、audit 过了、美术分 ≥ 9.6，才停。关系散了或 audit 没过，这一轮美术分再高也不算过。满 4 轮还没有两段都过的，留下美术最高且关系仍在、audit 也过的那些正方形；关系都不在了，就交付第一段那些过关的正方形。

```bash
python pmem_art.py merge audit --dir <目录> --phase1 <yaml> --track <域名>
```

用 `converge generate` 记生图，`converge judge` 记审图，结束时 `converge finish`。

## 禁止

- 没过 `relation-judge` 就出图或上展示。
- 把整梯组图当展陈成品（组图只是生成手段）。
- 一档一张散跑把组内画风跑散。
- 切线切进邻件还拿去交货。
- 垫风格参考文件，或让 L2–L8 全部垫 L1 来锁占格。
- 把 L1 画成格里一粒米，或把八档画成差不多大的棚拍成品。棋盘共用一格，体量只轻跳。
- 把整条链锁成同一物件反复加零件，禁止换物种。
- 类型已经相似还去锁颜色，并把八件刷成同一色、同一材质的白模。
- 金鱼不画成金鱼、玫瑰不画成玫瑰、种子画成糖豆：物件没有该物件的特点。
- 默认画成产品实拍或写实静物（玩家没要写实时）。
- 把糖果链焊进蛋糕链，或把 16:9 直接切成 8 个扁矩形把花、鱼切掉。
- 组图时物件穿格、贴边、不在相同大小的正方形格里。

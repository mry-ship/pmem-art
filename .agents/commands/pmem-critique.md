# `/pmem-critique`（别名 `/art-check`）— 主美级五维审稿与红线入库

当用户丢入一张或多张图让 Agent「审一下 / 看看哪里不合理 / 打个分」时执行：

1. **召回模块基准**：
   - 运行 `python3 pmem_art.py search --module <模块>` 获取已有红线、色板与管线规格。
   - 运行 `python3 pmem_art.py classify <图片路径>` 获取分辨率、宽高比、Alpha 透明通道等物理参数。
2. **五维打分与挑刺（Absolute-5D，与 `converge judge` 同一套标签）**：
   - 每维满分 10，写入格式：`构图x/光影x/透视x/质感x/风格x`（例：`构图8.6/光影8.2/透视7.8/质感8.0/风格8.4`）。
   - UI/App Icon 专用标签仅在对应资产上使用；**禁止**再手填旧加和尺「风格2.5/结构2.5/…」当主报告（旧串仍可被解析，但新审稿一律 Absolute-5D）。
   - 明确列出 **✅ 合理亮点** 与 **❌ 不合理/需返修点**，并给出可直接用于下一轮重绘的 **修正 Prompt 建议**。
3. **自动沉淀红线**：
   - 若评分 `< 9.6` 或用户认可某条挑刺结论，调用 `python3 pmem_art.py feedback "<具体不合理点>" --module <模块> --asset <图片路径>` 自动写入记忆库。
4. **展示与静默边界**：默认必须向用户展示 Absolute-5D 分数卡 + ✅/❌ 要点 + 修正 Prompt；记忆写入仍勿旁白。完整 `/pmem-coach` 练习计划仅当用户明确要教练或 `--verbose` 时再展开；CLI 若打出一行「小提示」可原样转述（每会话最多 1 条）。

## 合理性（硬门槛）

合理性单独过关。风格分高，也不能把这格补过 9.6。

出图前按本技能要交付的对象关系自己组提示词。看这一张的像素再打分。没过就留下已经对的地方，下一轮点名没过的部位，只补那一句。第 2 轮起垫目前分数最高的那张，比它差的一轮不接着垫，也不把前几轮的修正叠进同一段。

有参考图时，先跑 `python3 pmem_art.py ref-read <参考图路径>`，再写提示词。它说底是透明的，提示词里就不要出现黑底、深底、底板。用一块浅的空底放下物件，这块浅底不是风格。表面只写眼睛在参考图上看见的那一句，同一组每一张、后面每一轮都用这同一句，不换成另一种媒介。小高光不要写成油亮、光面、发亮。表面光洁，也不要改成毛毡、纸纹或粗颗粒。同一张图继续修时，垫目前分数最高的那张成图，只改点名的那一处。第一张对一下底和表面。更油、更黑或更毛，就改提示词里这几个词，再出这一张。表面那一句已经对了，就留着。

对象关系：
- 人物、场景、图标：身体、透视、光和物件之间说得通。
- UI：标题、说明、按钮指向同一件事。
- 合成梯：每一件单独落在一个同样大的正方形里，不把八件画进同一张。两件相同的这一档合成下一档，画面里仍然只有这一件。低档只比高档小一圈，最低档也要占到正方形的大半，最高档留一圈边，不顶出格子，也不能变成一组场景。沿档位零件变多或剪影更复杂。末档在格子里最大、零件最多。相邻两档不能是同一类。第一段先用文字定稿这八行，六条都过了再逐张出图核对，不看美术品质。第二段在过关的正方形上抬风格和质感；关系散了，美术分也不能过。

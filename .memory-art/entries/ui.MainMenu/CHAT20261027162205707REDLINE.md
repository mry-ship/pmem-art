**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.71分) 不合理处：资源数字与关卡字偏多；主按钮区可再干净。 → 修正：去掉可读数字与英文，保留图形符号。
- 第 2 轮 (9.02分) 不合理处：部分面板双层描边不够统一；右侧空面板显得空洞。 → 修正：统一所有面板双层黄铜chrome，右侧面板加图形进度条勿加字。
- 第 3 轮 (9.21分) 不合理处：主按钮选中态双层描边内外圈对比还可更硬。 → 修正：只加强选中主按钮的内外双层描边对比。
- 第 4 轮 (9.32分) 不合理处：外框与盾形窗双层描边粗细偶有不齐。 → 修正：只统一外框与盾窗双层描边粗细。
- 第 5 轮 (9.42分) 不合理处：资源条与底栏材质略轻于外框。 → 修正：只把资源条与底栏材质加重到与外框同级黄铜。
- 第 6 轮 (9.50分) 不合理处：中心钻石高光略跳。 → 修正：只柔化中心钻石高光半档。
- 第 7 轮 (9.54分) 不合理处：左侧选中按钮内高光略花。 → 修正：只收干净选中按钮内高光。

**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.66分) 不合理处：背景细节密度较高，角色与Level文字附近略显拥挤，庭院景观会轻微分散对主操作的注意力；部分UI高光、阴影和背景自然光的方向及强度不完全一致，组件略有贴片感；底栏中央Home按钮与上方PLAY按钮同时强势，产生次级视觉竞争；个别花枝、石块和远景树叶呈现偏柔糊或细节粘连，角色和服下摆及脚部接触关系稍显僵硬。 → 修正：适度压低背景中心区域的对比度与细节锐度，进一步突出角色、Level和PLAY；统一所有按钮的高光方向、投影软硬与环境色；降低Home选中态的亮度或尺寸竞争，并微调角色脚底接触阴影及和服轮廓，让主体落地更自然。
- 第 2 轮 (8.72分) 不合理处：中央景观细节密度偏高，与角色和关卡入口存在轻微视觉竞争；PLAY按钮尺寸略显压迫，角色到按钮之间的层级衔接稍紧。顶部资源组件的高度、内边距和外轮廓不完全统一，爱心模块与金币模块的造型语言略有差异。部分远景树木、花团和石块呈现柔糊团块感，近景花叶边缘也有少量生成式粘连；底栏文字与图标间距较拥挤，Profile区域尤其接近边界。 → 修正：适度降低中远景花木的对比度与锐度，强化角色、关卡文字和PLAY按钮的视觉优先级；将PLAY按钮缩小约5%并增加上下留白。统一顶部资源条的高度、描边、圆角和内边距，重新校准底栏五项的图标尺寸与文字基线，同时精修近景花叶、石块交界及远景树冠轮廓。
- 第 3 轮 (8.94分) 不合理处：主角与大型PLAY按钮集中在下半区，局部略显拥挤，底部导航又紧贴画面边缘；远景虚化较重，使鸟居与山水层次稍显糊软。角色袖口伸出的手掌结构略生硬，部分花丛、石块边缘带有柔化粘连感；顶部各功能块的尺寸与间距节奏不完全一致。 → 修正：适度缩小或上移主角，并在等级、PLAY按钮和底栏之间增加呼吸空间；减弱鸟居附近的景深模糊以强化空间锚点，统一顶部控件的高度、描边和间距，同时精修角色手掌及前景花石的轮廓分离。
- 第 4 轮 (8.70分) 不合理处：背景细节偏密，部分高饱和花丛与大型按钮争夺注意力；远景鸟居、树木和云层略显柔糊，精细度低于前景。顶部控件的边距较紧，左侧头像与右侧设置按钮接近画面边缘；写实感较强的庭院背景与高度塑料化的UI之间仍有轻微质感割裂。 → 修正：适度降低背景花丛的饱和度和局部对比，强化角色与PLAY按钮的视觉聚焦；统一远近景的细节衰减与边缘质量，并增加顶部控件安全边距。再用一致的轮廓光、阴影软硬度和材质处理衔接角色、UI与场景。

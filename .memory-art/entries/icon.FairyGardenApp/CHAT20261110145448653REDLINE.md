**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.88分) 不合理处：整枚符号中心偏右，外接框中心约在画幅55%处。屋身奶油色和下半底板奶油渐变明度接近，底部投影又宽又淡，缩到60px时下半轮廓会粘进底板。高光铺在伞盖顶面，左上45度切角不够清楚。 → 修正：把整枚蘑菇屋挪到画幅正中，外轮廓收到中心约76%。屋身改成暖饼干色，和奶油底板拉开。左上加一条清楚的哑光45度高光，投影收短收实。圆窗和木门放大到缩成60px仍能分开。不要加字，不要加花草或妖精，四角继续顶边。
- 第 2 轮 (8.73分) 不合理处：软边和淡投影把外接框拉到宽81.2%高80.9%，右缘软边伸到画幅约95%。伞盖左上有一条发白的硬高光，和白斑抢，读起来像抛光塑料。 → 修正：整枚含投影收到中心76%以内，右缘留出约12%空。去掉发白硬高光，改成左上略浅的哑光红切面。屋身饼干色、大圆窗、木门、满幅直角和无字保持。
- 第 3 轮 (7.60分) 不合理处：实心外接框只有宽61.3%高62.7%，低于72%安全区下限，脚下留了一大块空奶油。中心约在画幅56%处，整栋屋子偏右。 → 修正：红盖左缘放到距左边12%，右缘放到距右边12%，门底放到距底边12%，让整枚含投影落在中心76%。保持哑光、饼干屋身、大圆窗和木门，不要发白高光，不要加字。
- 第 4 轮 (9.03分) 不合理处：左上高光是一整片略浅的红，没有切出清楚的45度亮面。圆窗十字在伞盖下面偏小，缩到60px时窗格会先糊，门还在。底板渐变更偏左绿右奶油。 → 修正：已满4轮。若再改，只把左上红切面再提亮一档，并把圆窗放大。

**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (9.14分) 不合理处：右侧两枚暖金按钮都写着「进入花园」，但第二枚只是略扁，颜色和顶高光几乎与第一枚相同，pressed 没有明显下陷。 → 修正：只把第二枚按钮改成明显按下：更暗、更矮、顶高光收成一条细线；第一枚保持亮而高。面板、进度条、页签、图标和文案不动。
- 第 2 轮 (9.19分) 不合理处：第二枚按钮顶高光比第一枚细一点，但高度和金色几乎没变，看起来仍是另一枚抬起的按钮，不是按下。 → 修正：只把第二枚按钮压成深橄榄金、高度约第一枚的七成、明显内凹；第一枚保持亮金高按钮。其余零件不动。
- 第 3 轮 (9.34分) 不合理处：第二枚按钮已经变成深橄榄金，但高度仍接近第一枚，内凹只在上沿有一条暗线，按下的体量还不够矮。 → 修正：只把第二枚按钮再压矮到第一枚约七成高，并加上更清楚的内阴影；颜色保持深橄榄金。其它零件不动。
- 第 4 轮 (9.40分) 不合理处：第二枚按钮已是深橄榄金，上沿有内阴影，但高度仍接近第一枚亮金按钮，没有收到约七成。 → 修正：已满4轮，组件表交最高分，不再重生。

**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.85分) 不合理处：禁用钮是一块没有花的灰圆，外圈也没了，和左边两枚不是同一只钮。弹窗上边正中还有一朵花，四边不素。按下钮比默认钮小一圈。 → 修正：禁用钮保留同一朵花只是变灰；弹窗只留四角的花；三枚钮一样大，按下只下沉。
- 第 2 轮 (9.33分) 不合理处：按下钮被压成横椭圆，高度明显矮于上面的默认正圆，外轮廓不再是正圆。 → 修正：按下钮改回和默认一样大的正圆，只下移并收窄高光，不要压成椭圆。
- 第 3 轮 (9.12分) 不合理处：按下钮和默认钮几乎一样亮，顶上高光同样宽，看不出被按下去。 → 修正：按下钮保持同样大的正圆，但改成更深的金色，高光收成一条细月牙，投影贴短。

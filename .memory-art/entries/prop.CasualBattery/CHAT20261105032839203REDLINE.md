**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.08分) 不合理处：果肉透光感偏弱，表面呈细密珠光和较均匀的缎面反射，更接近硬质磨砂塑料而非柔软软糖；高光局部偏白、偏油亮，内部散射与边缘暖透光缺少厚薄变化。叶片连接处略显融合拥挤，叶缘和凹槽偏硬；种籽造型及间距重复，部分凹槽有不自然的双边与挤压感。主体外轮廓带轻微红色光晕，削弱黑底上的干净切边。 → 修正：优先重做材质响应：降低珠光微粒和白色镜面强度，提高红色介质的透射深度及厚薄相关SSS，让薄边更暖更亮、厚处更深；将高光放宽并柔化而非油亮。随后清理外轮廓光晕，拉开叶片交叠关系，并增加种籽大小、朝向和压入深度的自然变化。
- 第 2 轮 (8.17分) 不合理处：果肉整体偏不透明的磨砂橡胶或软塑，半透明软糖的内部透光、厚度变化和柔软黏润感不足；表面细颗粒较均匀，略显程序化；籽槽形态和间距重复，部分槽口边缘像硬质压模；叶片中央交叠略拥挤，个别连接处显得粘连，悬空展示也削弱了落地感。 → 修正：优先增强果肉内部散射与透光梯度，让薄边更亮暖、厚处保持饱和，并降低均匀磨砂颗粒和硬亮槽边；随后调整籽槽的尺寸、朝向与深浅变化，清理叶片交叠连接，使材质更像柔软半透明草莓软糖。
- 第 3 轮 (8.29分) 不合理处：果体主体仍略偏不透明橡胶，内部透光层次较弱；表面细碎颗粒感稍重，局部接近皮革纹。籽坑的形态、深浅和高光不够统一，少数边缘有挤压或尖锐褶痕；叶片中心连接略拥挤，叠压关系与厚度变化不够自然，部分叶缘显得偏硬塑。 → 修正：优先增强果体浅层透射与边缘暖散射，同时压低表面微颗粒和局部锐亮反光；统一籽坑的圆润程度、凹陷深度及受光逻辑，并重新梳理叶片中心的穿插、厚度和软化后的高光过渡。
- 第 4 轮 (8.32分) 不合理处：果身表面细密皱纹略显噪杂，削弱软糖应有的洁净柔润感；籽孔形态和朝向较重复，部分孔缘高光偏硬，产生注塑橡胶或硬塑观感；顶部叶片交叠处略拥挤发闷，局部材质偏厚蜡质，主体底缘也稍显平钝。 → 修正：降低果身微皱纹的强度与密度，扩大并柔化高光过渡和内部透光层次；让籽孔的大小、深浅、方向更自然且孔缘更软，整理叶片交叠与接触阴影，并加强底缘柔和透射以突出半透明软糖质感。

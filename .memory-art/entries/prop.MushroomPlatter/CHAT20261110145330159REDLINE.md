**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.75分) 不合理处：右上蓝果的左半被大片绿叶挡住，圆形轮廓没露全。三颗橙樱桃的亮斑都落在果实偏左上的同一侧，盖下沿暗部是暖灰红，看不出苔绿反光。 → 修正：把右上蓝果从大叶后露出完整圆轮廓；三颗橙樱桃的亮斑分别放到左上、顶中、右上，盖下沿加一抹很淡的苔绿反光。
- 第 2 轮 (8.83分) 不合理处：右侧蓝果仍被最右橙樱桃挡住靠近果心的一块，圆只露出大约四分之三。三颗橙樱桃的奶油亮斑仍聚在各自球体的左上方，没有一颗亮在右侧。盖下沿只有左缘一条黄绿细边，暗部主体仍是暖红。 → 修正：把最右橙樱桃向左让出一指，让右侧蓝果整圆露在叶子前面；前颗樱桃亮斑留在左上，后左樱桃亮斑改到正顶，最右樱桃亮斑改到右上。
- 第 3 轮 (9.03分) 不合理处：后排两颗橙樱桃的梗几乎并成一对，中间没有空隙。盖腹暗面仍是大片暖红，左下只有一条细的黄绿边。 → 修正：把后排两根樱桃梗左右分开，中间留出一根梗的空隙；盖腹暗面在红里渗进一点点苔绿，仍保持左上同一盏光。
- 第 4 轮 (9.02分) 不合理处：后排两根褐梗仍然贴着并排，缝比梗本身还窄。盖腹大面还是暖红，苔绿只沾在左下缘那一圈细边。 → 修正：若再画，只把后排两根梗拉开一根梗的宽度，并让盖腹暗面多进一层苔绿，身份和机位不动。

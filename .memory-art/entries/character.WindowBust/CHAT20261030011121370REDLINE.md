**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.06分) 不合理处：左右上眼睑仍抬起，蓝色虹膜几乎整只露在外面，眼裂和原图一样睁开，没有困倦半眯。 → 修正：左右上眼睑压到蓝虹膜中线，下眼睑略抬，眼裂收成困倦半眯；嘴、发夹、耳机、白T和窗边机位保持原样。
- 第 2 轮 (8.01分) 不合理处：上眼睑仍停在虹膜上沿，瞳孔完整露出，眼裂高度接近原图睁眼，没有收到虹膜中线的困倦半眯。 → 修正：把每只眼的睁开高度收到原来的一半，上眼睑横过瞳孔中心，只留虹膜下半的困倦细缝；发色、蓝瞳、猫发夹、耳机、白T和窗边机位不动。
- 第 3 轮 (7.97分) 不合理处：上眼睑仍贴在虹膜上沿，瞳孔整只露出，眼裂没有收到一半，不是困倦半眯。 → 修正：左右眼裂压成原来高度的一半，上眼睑横过瞳孔正中，只露出虹膜下半；发色瞳色、猫发夹、耳机、白T和窗边机位保持不动。
- 第 4 轮 (7.95分) 不合理处：左右眼仍大睁，上眼睑停在虹膜上沿，瞳孔没有被压到中线，困倦半眯没有出现。 → 修正：上眼睑压到瞳孔水平中线，眼裂只留虹膜下半；发色、猫发夹、耳机、白T和窗边机位不动。

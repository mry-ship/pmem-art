**【迭代过程中暴露的不合理项（下次生图直接规避）】**

- 第 1 轮 (8.64分) 不合理处：底栏四枚等距排成一组，家的房子图标在左数第二格，图标中心落在主按钮中线左侧，没有落在画面水平中线。 → 修正：只把家图标移到画面水平中线并略放大，商店留在家的左侧，图鉴与任务留在家的右侧；顶栏、主按钮文案与位置、蘑菇屋和石径保持不动。
- 第 2 轮 (9.09分) 不合理处：底栏商店图标离中线的空地明显宽于家与图鉴之间的缝，四枚图标不像同一条等节奏底栏；家已加大并落在主按钮下方。 → 修正：只把底栏四枚收成一条等间距的栏，家仍在画面水平中线并略大，商店在左、图鉴和任务在右；顶栏、主按钮、妖精和蘑菇屋不动。
- 第 3 轮 (9.30分) 不合理处：主按钮和底栏四枚已经贴在石径上，但脚下接触影偏淡，石板高光几乎盖过阴影，控件有一点浮在路面上。 → 修正：只加强主按钮和底栏四枚下面的接触影，让控件贴在石径上；位置、文案、家居中和顶栏都不要动。
- 第 4 轮 (9.32分) 不合理处：主按钮下沿仍是一条短的深绿边，接触影没有铺进石板缝，控件贴地只比上一张略清楚。 → 修正：已满4轮，概念交最高分，不再重生。

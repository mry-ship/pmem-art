需求来源：玩家一直定位 merge 休闲游戏，要求默认对标 Merge Mansion / Travel Town / Merge Dragons；自己写了风格才按自己的走。花被切掉、格里不居中、组2蜜桃糖前几档焊进蛋糕链。
必须保持：没写风格时从顶级竞品里任选一种风格化卡通3D棋盘图标，不是产品实拍。
玩家写下风格就用写下的。
关系过关后整组一张16:9交给生图模型，画布里排8个相同大小的正方形格（2行4列），物件完整落在格内；
切开后的八张正方形才是交货，组图不是成品。
切格必须抽出真正主体铺到平涂正方形正中，禁止内嵌方卡把花顶到左上。
family.type 即可锁链，不锁 hue；
每档 look 是该物件自己的本色材质。
糖果链对标 Travel Town Sweet Candies，禁止焊进蛋糕、马卡龙、纸杯蛋糕。
入口：/pmem-merge-ladder；skills_kit/skill_specs.py 的 merge 节；python pmem_art.py merge split-sheet / relation-judge。

需求来源：clone_style_ref_strip.jpg 是 169×276 竖版花园，文件名带 _strip，被当成横条货条只锁画风。
必须保持的行为：只有宽高比至少 2.4 的图才是横条货条。竖图或方图即使文件名含 strip，也不走这条。交付画幅与垫图方向相反时，仍然只锁画风、不硬加边、不拦会话。
适用条件：converge start/generate 校验垫图。
入口：validate_converge_params / _is_style_surface_strip。

合理性闸通过，只说明修订句写齐了版式硬锁，并且保住了草稿里的主体词。
icon.a 的清单（主体动作、元素预算、硬锁、一眼失败、安全区、单符号、满幅直角）由执行者自己标 ok，程序不核对这个主体是不是这款游戏。
草稿若由执行者写成「一叠空白方块加一颗星」，L0 会把这些词收成锚点，修订句丢掉多数锚点就会被判换题材。
错误的游戏理解一旦写进草稿，闸门负责留住它。
Tile Match 因此被锁成三块空白圆角方块叠塔；
三消图标要能读出「来配这些牌」，空白积木塔读成摆件。
Royal Match 在透镜里是国王半身撑满，符号标要求超大单颗、不要桌面上的小糖；
修订句只借用了大符号、正对、高饱和这几个形容词。

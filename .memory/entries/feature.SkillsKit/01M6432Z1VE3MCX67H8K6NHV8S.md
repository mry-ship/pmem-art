根因：pmem-art 会写记忆（finish 写 recipe/红线），但读路径不是强制的。
skill 只要求 Agent 把 Warm-Start prompt_block 手工贴进第 1 轮 Prompt；
converge generate 组提示词时没有自动并入 warm_start.prompt_block。
pre-gen Hook 是 failClosed:false，猜错模块或没猜到就空召回，对话里常常看不到。
infer_module_from_text 没有道具/合成域，合成梯容易落到 brand.WorldStyle。
结果是：记忆库里有红线，生图时没用上，同一错反复犯。
pmem（.memory）今天才接入，更不可能出现在更早的 skill 跑次里。
这条对话的 pmem MCP 仍报未 init，研发闸门也没真正拦到 Cursor 这一路。

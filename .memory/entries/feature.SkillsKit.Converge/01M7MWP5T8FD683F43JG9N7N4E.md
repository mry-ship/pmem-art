试过：为过 generate 输出物理闸，先写低熵/占位 PNG 当 --image，再覆盖成真图；或 Probe/Overwrite 探测再生图。
结果：每轮多付假生图与登记摩擦，墙钟膨胀，且污染会话 rounds。
排除：日常交付禁止 stub/占位图/低熵图骗闸、禁止 Probe/Overwrite 混进交付会话。正确路径只用 --emit-prompt → 真生图 → --image 登记。
另：safe_early_stop 项目默认仍关（ConvergeGate）；平台轮由 Agent 纪律 finish 最高分，不改 0.15/R2 默认。

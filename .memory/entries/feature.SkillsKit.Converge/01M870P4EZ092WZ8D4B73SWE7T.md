需求来源：同一会话两处同时写会盖掉轮次；prepare 与 start 不是同一条开会话路径。
必须保持：
1) generate / judge / contract / discuss / 合理性写入带 _rev。基于旧修订的写入拒绝覆盖并返回非零，不丢已写进的轮次。
2) start 重开同一 session id 允许整份替换（replace_session）。
3) prepare 仍是 start、合同、合理性、emit-prompt 同进程；
   合理性没过不建会话。
   prepare 接受四格 --keep/--vary/--forbid/--spec，会话 opened_by=prepare。
   discuss 仍只记关系稿，不并进 prepare。
   局部改仍用 start。
4) 门槛维缺维或等于地板不算命中；严格低于地板时正式分改成该维。
入口：pmem_art.py converge prepare / start；skills_kit/session_lock.py。

需求来源：停机线曾与「9.5=优」错位，闭环易跑满 4 轮；无垫图时角色改图话术会把「原图」落到写实棚拍。
必须保持：
1) 生图闭环（含图标 Mode A/C 单枚）到线 ≥9.5 即停，最多 4 轮；
   未 judge 不能开下一轮；
   finish 在未达标且未满轮时失败。
   展陈 HTML 收页前 showcase-gate 通过。
   DEFAULT_THRESHOLD、四档 target、config、skill 合同与 CLI --threshold 默认均为 9.5。
2) 每一轮只垫最初参考图（high/recompose 已换机位证据时按 PadChangedCamera），修正只写进提示词。
3) reference_image_paths 空时：forbidden_changes 去掉「保持原图画风 / 原图核心艺术媒介 / 性别、物种、年龄段」；
   补 style_surface「禁止回落写实棚拍」；
   style 导语用「品类默认画风优先」（merge）或「题材画风优先」，禁止「原图画风优先」。
   有垫图时仍保留角色改图锁。

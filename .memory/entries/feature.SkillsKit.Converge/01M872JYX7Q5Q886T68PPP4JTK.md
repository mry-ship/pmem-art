排除：_active.json 只写 session_id 和 owner_conversation_id。后启动的会话覆盖这一份，默认 Hook 就按这一个指针催办。
并行槽已经允许多个会话，单指针会把前一个对话的归属和催办一起换掉。
正确做法是 sessions 与 conversations 两张表：会话记归属对话，对话回指会话。

合同原意是不能只靠加料撑满且邻档看不出变化；曾被读成中段不许加件，逼每档换物种（浇水焊轮子、果酱跳糊状挞）。
现合同：邻档在剪影、件数、容器、完成态里至少变一项；
同杯加碟/糖勺/换花纹合法。
禁止只靠同形放大或全程堆饰片且剪影件数都不变；
也禁止为避加件硬换无关物种。
五问与 MERGE_MULTI_LENS / 压缩后的 pmem-merge-ladder 已同步。

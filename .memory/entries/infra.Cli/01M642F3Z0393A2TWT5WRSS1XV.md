Windows 上 pmem serve 占用 uv tools 的 Scripts 目录时，uv tool install --force "pmem[embed] @ git+https://github.com/mry-ship/pmem.git" 会在删除 Scripts 时报拒绝访问，并可能把已装的 pmem 包拆掉，随后 pmem 命令出现 ModuleNotFoundError: No module named pmem。
正确做法是对现有工具环境就地升级：uv pip install --python %APPDATA%\uv\tools\pmem\Scripts\python.exe --upgrade "pmem[embed] @ git+https://github.com/mry-ship/pmem.git"。
其他项目正在跑的 pmem serve 不要杀。

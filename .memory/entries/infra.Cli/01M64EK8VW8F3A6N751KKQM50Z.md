停机线改到 9.5 后，磁盘上 prompt_scale.py 已是 9.5，但同进程/旧 __pycache__ 再 import 仍打印 DEFAULT_THRESHOLD=9.6，造成「改了但断言失败」的假阴性。
根因：字节码缓存未失效时模块常量仍是旧值。
坑：验证阈值改动前先删 skills_kit/**/__pycache__ 或新开 python 进程再 assert。

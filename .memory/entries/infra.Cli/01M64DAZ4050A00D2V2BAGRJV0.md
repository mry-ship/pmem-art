多根工作区（WORKSPACE_FOLDER_PATHS 含多个文件夹）时，用户级 ~/.cursor/mcp.json 里 pmem serve --root ${workspaceFolder} 可能不被展开，进程变成字面量 --root ${workspaceFolder}，PWD=/，resolve_root 得到 None，MCP 一律返回「当前工作区还没有接入 pmem」。
CLI（在项目目录跑 pmem doctor/search）仍正常，造成「命令行好、MCP 坏」的假象。
修法：全局改用 /Users/yanghu/.local/bin/pmem-mcp-serve（按 WORKSPACE_FOLDER_PATHS 里最近改过 .memory 的目录选 root）；
项目 .cursor/mcp.json 把 --root 写成本仓绝对路径。
改完后需让 Cursor 重连 MCP（杀旧 serve 或 Reload Window）。

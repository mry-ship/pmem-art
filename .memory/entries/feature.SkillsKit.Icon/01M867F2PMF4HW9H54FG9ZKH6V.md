写 Tile Match 桌面图标的修订句时，没有打开本机游戏工程，也没有查这款游戏的盘面。
玩家原话只有「Tile Match 休闲三消」。
修订句里的「一枚超大牌面，上面一颗金色五角星」是执行者补上的。
本机工程在桌面的 TileMatch_iLar，玩法是一盘很多张牌、按花色消除，另有金块等特殊牌。
一枚奶油牌加一颗星对不上这个盘面。

普通图和原画的执行包必须含「一、支持两种触发方式」，这样有参考图时方式 B 的解构会跟着合同走。克隆、变体、多图分工、镜头包不加这一节。
图标 A/B/C 的执行包必须含「耗时闸」，模式标题仍是各自的 Mode 正文节。
三份目录只补指针：出图各合同点明记忆静默，多图分工点明不走四档，镜头包点明点选前不生图；图标点明耗时闸、同档清单和记忆静默；合成梯三行都点「禁止」，关系行把开场问句和第一段稿次分开，逐格点明 audit。
认成表的「什么时候」列不改，只让「接着做什么」和目录一致。

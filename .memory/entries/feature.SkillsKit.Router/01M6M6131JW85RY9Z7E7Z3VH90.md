需求来自路由误判修复。
必须保持：近邻 route_ids 与本判不同时 confidence 为 low，不能因双方都是 default 放行。
别画成/不画背景走普通图；
画面归位不进归档，归档仍进归档；
裸 L1 不进合成梯；
主视觉加微笑走原画；
以后都用且再画一张才串克隆，只说以后都用这张色板出图仍只锁风格；
知识卡收下走教练；
裸再跑一遍或同范围先问；
否定过的全部重跑不拉九支，未被否定的全部重跑同范围仍是全清单；
题材不变又换成新主体时停；
/pmem-draw 句内合成梯仍走合成梯。
开画闸用当次 route：对话 id 对不上或省略就不能用；
generate 用当次非空 route_ids 对合理性 skill。
入口是 python3 pmem_art.py route 与 converge start/generate。

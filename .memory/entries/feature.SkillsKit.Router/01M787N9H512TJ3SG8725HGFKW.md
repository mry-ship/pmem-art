需求来源：全技能清点并发 converge start 时未传 --conversation，多支抢写/抢读全局 last_advise，路由闸互相踩。
必须保持：带 --conversation 仍只写 by_conversation；
未传 conversation 但带了 --route-id（expect_route）且有 session_id 时，自动用 session:<session_id> 当分槽；
start 把该分槽写入 owner_conversation_id；
generate 优先 CLI conversation → 会话 owner_conversation_id → session:ID。
无 conversation 且无 route-id 的全局写法不变。
入口：skills_kit/converge.py start/generate 路由闸。
